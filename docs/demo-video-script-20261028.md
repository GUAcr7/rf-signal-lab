# 功能演示视频拍摄与讲解稿

按约三分钟准备初稿，最终时长按作品提交通知调整。本稿对应现有受控有线、单发送源、三类调制、电脑辅助控制版本，不启用TX2或频谱仪。当前P83已停止归档，拍摄前须重新检查并校准、启动屏控；不是现在拿起屏幕就能继续上一会话。

## 拍摄前准备

- 保持旧P201 TX1 → 原衰减连接 → 新TLZ7xH RX1A。淘晶驰屏仍通过USB-TTL接电脑；电脑必须开机运行控制程序，不需要互联网。
- 由AI重建接收会话、采集背景、发参考单音校准，再开启快速屏控。不要把CALIBRATION_REQUIRED、RX STOPPED或旧画面作为正在工作的演示。
- 手机横屏固定，先测试是否能读清屏幕文字；避开反光。拍摄者与操作者分工更方便，也可以先录真实操作，后配旁白。
- 实物全景中保留两板、衰减连接、小屏和电脑。关键按键→实际发射→接收识别保留连续片段；阶段间可以剪接，等待若加速需标明。
- 每次默认15秒发射，解说较长时可多拍一轮同样信号，不一边长篇介绍一边等它自动结束。控制窗口和新板接收期限均有限，正式录像在AI确认就绪后再开始。

## 建议拍摄顺序

| 段落 | 拍什么、做什么 | 重点讲什么 |
|---|---|---|
| 开场，约15秒 | 两块板和显示屏的全景 | 三项功能：可视化、参数估计、支持类别的AI识别 |
| 结构，约20秒 | 手指依次指发送端、衰减器/同轴线、接收端、电脑 | 真实射频经有线传输，电脑负责控制及校准，分析和识别在板端完成 |
| 时频显示，约25–35秒 | BPSK→APPLY→READY→START→RUNNING；镜头切到新板 | 左上I/Q、右上频谱、左下瀑布图，顶部序号持续更新 |
| 参数，约20–30秒 | 仍在有效信号期间拍右下；需要时再开一轮BPSK | LO+center、99% ROI BW、Center offset、Above background及单位 |
| AI切换，约50–70秒 | 实际选择QPSK、16QAM，各APPLY→READY→START，分别留稳定识别片段 | 发射端当前选择与接收端模型分类一致；谱形不必明显不同 |
| 停止，约15–25秒 | 再次启动BPSK，在RUNNING时点STOP；保留结束过程 | 停止发射后接收程序仍运行，信号消失后不保持旧的有效分类/参数 |
| 收尾，约10秒 | 回到全景 | 已完成受控三类的采集、分析、识别联动，后续拓展空间监测 |

若运行的是验收自动退出入口，完成全部预设操作后控制屏可能显示OFFLINE，表示控制程序正常关闭。要拍清停止后的IDLE和接收变化，可在完成最后一个自然发射预设之前先拍一次RUNNING中STOP，最后再补余下调制种类。STOP停止发射，RX STOPPED表示整个接收程序结束，两者不能混讲。

## 操作者逐步做

1. 选BPSK，点APPLY，等READY；点START，等RUNNING。让镜头拍到新板动态画面与稳定的BPSK分类。15秒到时源端结束。
2. 再开一轮BPSK可用于参数特写；若要先拍STOP，本轮等RUNNING后约3秒点STOP。
3. 选QPSK，重新APPLY→READY→START，拍接收端稳定QPSK结果。
4. 选16QAM，重新APPLY→READY→START，拍接收端稳定16QAM结果。
5. 若尚未拍停止且控制程序仍开放，再开一轮BPSK，在RUNNING时点STOP。不要将自然15秒结束当主动停止。
6. 完成后告知AI，按本次日志检查实际收到的按钮和自然结束/STOP，停止接收并保存数据。手机录像文件还需另外导出归档。

## 新板四区画面怎样讲

- 左上：AD9361下变频、采样得到的I/Q数据的时域片段，不是直接显示2.45GHz射频正弦周期。
- 右上：数字频谱，横轴是相对于接收本振的频偏；底噪和有效信号分开观察。
- 左下：将多次频谱显示快照按顺序叠加，颜色表示谱强度。不能称连续ADC时间轴或用它证明无丢样。
- 右下：当前选定分析区域的参数。LO+center为本振加区域中心偏移的频率估计；99% ROI BW为该区域按能量区间计算的带宽；Above background为相对背景的dB值，ROI power为counts^2。不是已标定dBm，也不是已证明满足某种标准的绝对仪器测量。
- 底部AI区：轻量模型对实际接收数据给出当前支持类别。看到稳定BPSK/QPSK/16QAM时再讲对应类别；切换过渡可能暂时无信号或不确定，不宣称任意信号均能分类。
- 顶部update/source block：表示更新与来源块推进，不等同ADC无丢样帧率。每种信号拍清持续变化至少数秒。

## 可直接配音的讲稿

大家好，本作品基于Zynq异构平台和AD9361射频收发芯片，实现射频信号采集、时频域可视化、参数估计，以及轻量化AI调制识别。下面通过真实射频收发演示这三项功能。

左侧是可切换调制类型的发送端，信号经同轴线和衰减器进入右侧接收端。AD9361完成射频收发与采样，FPGA承担高速数字接口、数据搬运和显示相关通路，ARM侧完成频谱分析、参数计算与模型推理。电脑用于本轮控制和校准。

首先选择BPSK，应用配置后启动发送。接收屏左上显示I/Q时域波形，右上显示频谱，左下瀑布图展示多次频谱更新的变化。可以看到画面和来源序号持续更新，数据来自板卡实际接收。

右下显示选定分析区域的中心频率估计、99%区域能量带宽，以及相对背景功率。这里展示的是当前配置下的估计和相对读数，尚未做独立仪器的绝对功率标定。录制时可按屏幕实际数值举例，保留MHz、kHz和dB单位。

接下来将发送信号依次切换为QPSK和16QAM。每次重新应用并启动后，接收端对采集数据执行轻量化模型推理，并显示对应调制类别，展示当前模型支持的三类信号识别能力。

现在启动一轮信号并按停止。发送结束后，接收端继续观察输入，信号消失后回到无有效信号状态，不继续保留旧的有效分类和参数。

本次演示完成了受控射频信号从发送、采集，到可视化、参数估计和AI识别的功能闭环。系统可用于射频教学与受控信号分析验证，后续可进一步接入天线，拓展空间射频监测应用。

## 简介建议修订

可保留用户原简介的三项核心任务，但将“利用FPGA高速并行处理与AI算法”明确为上述FPGA/ARM分工，不暗示CNN已经在PL硬件加速。将“可用于对所处空间射频信号的检测”改为“面向射频信号检测与分析，已完成受控有线链路验证，可进一步拓展至空间射频监测”。

视频不使用“任意信号均可识别”“识别准确率100%”“完全脱离电脑”“功率已精确标定”“连续无丢样”作为本版本成果。三种调制使用相同符号率和成形时，频谱外观可能相近，AI演示重点是对应类别与实际收发联动，而非三条频谱必须肉眼明显不同。

本轮最新P83仅记录BPSK，其余两类与STOP完整人工证据来自P81。正式视频须实际拍齐需要展示的操作，不能将脚本中的计划当成已经拍摄或通过的本轮结果。
