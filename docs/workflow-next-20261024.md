## 1. 最终要交付什么

做成一套可实际操作的双板射频测试系统：

- 旧 P201 接触摸屏，选择信号类型和已验证参数，控制发射与停止，保存常用配置。
- 新 TLZ7xH 接收真实射频，在小屏显示波形、频谱、指标和独立 AI 识别结果。
- 从旧板同一个 TX1 输出分出测量支路，连接已有 RIGOL RSA3030 频谱分析仪，对照频率、带宽与功率。
- 普通使用有固定操作入口，异常有明确提示；每轮结果可以保存并复现。

用户已明确：验证仪器仍是此前使用的 RSA3030，测量对象仍是射频信号。当前不新增低频模拟输出/DAC方案。新增“监测口”优先用外置射频分路器件实现，不以第二路 TX2 复制信号作为同一路输出的测量替代。

```text
旧板触摸屏 → 旧 P201 控制程序 → TX1 → 50Ω射频功分器/定向耦合器
                                      ├→ 接收支路及合适衰减 → 新板 RX1A → 分析/AI → 新板屏幕
                                      └→ 测量支路及合适衰减 → RSA3030 RF INPUT
```

射频线只作为信号通路。两板配置、校准、状态协调需要单独明确控制通道或各自的操作入口，不能假设插上射频线即可传递控制命令。发送标签只用于独立验收对照，不输入接收分类器。

工作编号W0～W7仅用于本计划，不覆盖现有P编号实验。

| 顺序 | 工作 | 必须交付的成果 | 开始时状态 |

| W0 前置 | 固定恢复、校准与启停入口 | 可重复使用的控制入口、状态检查和恢复说明 | 部分基础已有，待整理 |
| W1 最高 | 旧板触摸屏信号源 | 实物屏可选择波形、设参数、发射、停止、保存配置 | UART离线候选，未接屏验收 |

| W3 高 | 新板显示和测量功能完整化 | I/Q、频谱、瀑布图、指标/AI页面及必要操作 | 频谱/AI已有，其余待集成 |
| W4 第一版收口 | 十分钟整机演示与交付 | 固定演示步骤、完整记录、恢复包和备用视频 | 新功能完成后验收 |

W1和W2可以分别开展离线准备；W3的界面、算法参考不必等器件到齐。实板操作由一个任务独占，不能同时抢串口或建立第二个接收上下文。W4必须在W0～W3相关功能集成后进行。

W6是[既有实施指南](implementation-guide.md)明确要求的最终交付项，必须真实实现并验收PL频谱处理，不能降为可选扩展。这里按“先完成用户当前可操作展示，再深化”的顺序安排；W5/W6可并行，若时间有限，优先闭合W6既定验收，再扩大W5的新场景。W4只代表第一版演示系统验收，不等于全部项目已完成。官方比赛条款仍以原文为准，本轮没有重新核实官方赛题，不能把项目计划声称为官方条款。

## 4. 每阶段怎么做、怎样算完成

### W0：固定恢复、校准与启停入口

1. 复用P58已验证的身份检查、校准和安全收发逻辑，整理成固定入口；取消每次临时改参数或临时生成执行脚本的依赖。
2. 明确新会话、停止、重新开始和异常恢复状态。依据实际设备身份查找端口，不把COM8/COM9当作永久身份。
3. 每次上电检查boot身份和当前接收进程；已有接收会话优先复用，结束记录不能当作正在接收。
4. 校准要求本次会话有效：背景阶段确认源关闭，再执行单音校准；沿用现有模型/校准绑定机制。涉及采样率、频率等变化时重新判断校准是否失效。
5. 明确脱离电脑的实现方法：旧板屏控制本地发射；新板须有本地校准/启停入口，或经验证的板间控制通道。在此之前，电脑入口只算调试工具，不标“完全独立使用”。

**交付/验收：**操作说明、固定入口、状态记录；一次完整的启动→校准→收发→停止→重新开始成功，错误状态能解释且不会误用旧结果。纯文档整理不触发无必要的整套硬件重测。

### W1：旧板触摸屏可控信号源

**A. 先把独立串口做实。**复用[UART候选记录](experiments/exp-p201-uart-candidate-20261024.md)。审核现有外部时序/跨时钟报告与原厂基线差异，确认启动初始化，准备可回退的启动包；不得仅凭布线成功宣称可部署。先无外设验证启动及原电脑控制台，再进行物理串口回环，最后接屏。

候选是PS UART0经EMIO到J19第5/6脚（E17/E18），名义3.3V；这些是候选分配，不是当前可直接接线的结论。核实实物版本、方向、电平和GND；J19前四脚是电源，不能当作地。目标屏完整型号、供电和串口逻辑电平需分别确认。

**B. 做出能操作的控制页。**第一版提供单音、BPSK、QPSK、16QAM；参数采用经过验证的频率/频偏/符号率/幅度预设。支持应用、开始、停止、定时发送、当前状态和配置保存。请求值与实际应用值分别处理，板端确认后才显示“已应用”。

**C. 把控制与发射结合。**修改配置先停止，检查后应用并读回；处理重复触摸、错误命令、通信中断和停止失败。屏幕传结构化参数，不传任意shell命令。上电默认待机；现有单次发射最长60秒的保护不因新UI被绕过。十分钟演示可包含多个有界发送窗口，不要求连续发射十分钟。

**D. 解决重启后的文件恢复。**旧板当前源文件位于RAM，断电会消失。核实可用持久存储与启动方式，保存程序、预设、波形及哈希清单；准备自动恢复文件但不自动发射的方案。在完成前，不宣称“只接电即可使用”。

**交付/验收：**屏幕工程和下载文件、板端控制程序、协议、参数表、接线说明、恢复包；实体触屏可启动/切换/停止，状态与实际输出一致；重新启动后能恢复预设且保持待机，原电脑控制台和RF链仍可用。

### W2：同一路射频分路及RSA3030对照

1. 从TX1分路，选择覆盖实际频段、50Ω且功率能力合适的功分器或定向耦合器；记录准确型号、连接方向、衰减器和未用端口终接要求。普通T形接头不能代替已选定的匹配分路器件。
2. 改线前停止发射。分别核对新板接收端和频谱仪输入范围，重新核算两支路功率；不沿用旧接线下未经验证的损耗假设。
3. 先单音测两路损耗与频率，再用调制信号比较带宽/相对功率。首轮沿用已验证的有限时低幅度条件，不自动提高输出。
4. 记录RSA3030中心频率、跨度、RBW/VBW、检波/平均方式、输入衰减、迹线模式和标记位置；每组清除不适用的历史Max Hold。比较带宽需使用一致的定义；比较功率需换算到同一参考位置。
5. 固定接收增益作功率对照。未完成校准时继续显示数字/相对功率；完成校准也只在标定范围内使用dBm。绝对功率精度可后续完善，不阻止先完成频率、带宽和相对变化验证。

**交付/验收：**实际接线图/照片、器件清单、两支路损耗表、原始I/Q、仪器截图及误差表。误差容限在试验前按分辨率和仪器条件确定，不看完结果再放宽。频谱图不能单独作为三类AI全部正确的证据；矢量解调/EVM需要确认仪器选件或另建独立分析。

### W3：新板完整显示与操作

1. 保留当前频谱/AI基础，增加I/Q时域和瀑布图页面；需要时进行分页，不在800×480屏上堆叠过多信息。
2. 加入定义明确的信号中心频率、占用带宽、相对功率，以及采样参数、AI结果和处理时间。峰值频偏与中心频率分开；接收滤波器18MHz配置不能直接显示为测得的信号带宽。
3. 用独立参考验证测量算法，包括无信号、噪声、带边/截断和多峰情况；没有有效目标时显示无效/不确定，不能将整段噪声区间误称目标带宽。
4. 增加页面切换、校准、开始/停止等必要操作；确认使用新板现有触摸输入或经验证的控制通道，不能把旧显示模式下触摸测试当成新原生界面已接入。
5. 明确校准中、RX运行、无有效信号、不确定、停止和错误状态；停止时不保留看似有效的新分类。I/Q、谱、指标与AI结果绑定相同来源块或明确各自时间。
6. 瀑布图按实际收到的块或主机更新时间标注；连续ADC时间轴、无丢样声明需要额外证据。处理时间区分算法计算、UI刷新和端到端时间。

**交付/验收：**新显示程序及界面说明；已知信号的数值复核、实际显存与同源I/Q归档、实体屏幕可见性确认。电脑已有图形不算LCD已实现。星座/EVM属于可扩展页，须先有可靠同步/解调依据。

### W4：第一版十分钟整机交付

按固定步骤完成启动与新校准、三类信号切换、参数预设变化、仪器对照、页面切换、停止与恢复。连续观察屏幕十分钟即可作为当前展示时长目标，不重复开展用户不需要的长时间测试。

保存收发参数、窗口时间、完整必要日志、代表性同源I/Q/显存、仪器读数和演示视频；统计十分钟中实际发送/接收/分析的覆盖范围，不将等待时间写成持续分类。冷启动持久文件有变化时追加一次真正断电验收；没有相关变化不机械重复已经通过的冷启动试验。

**交付/验收：**演示操作卡、结果对照表、全部必要文件与恢复包。十分钟内无意外黑屏/失控/不可恢复卡死；停止后状态准确、资源释放；正常使用不需要改脚本。未完成脱离电脑控制链时，如实标明仍依赖电脑的步骤。

### W5：自动测量及AI可靠性

把人工选档变成可重复的自动测试：在已验证范围内逐步改变频偏、强度、符号率，保存测量误差、识别覆盖率、已分类样本准确率、拒识比例和失败样本。先完成一个变量的受控试验，再扩大组合。

按独立原始波形/采集会话分组保留新的训练、验证、最终测试数据；最终测试前冻结模型、预处理和阈值。不复用已暴露seed2313～2315作新独立成绩，也不从测试结果反调后继续报同一成绩。未知/多信号测试另列，不以三类封闭分类成绩代替通用识别。

**交付/验收：**自动测试入口、适用参数范围表、混淆矩阵、拒识/误识记录、速度与误差报告。新增模型/前端使用新版本，原冻结P52/P56与实测基线保留。

### W6：FPGA深度使用与最终交付必做项

正式PL FFT/功率谱必须在最终完整交付前通过；显示版可先交付演示，不能用演示通过将本项结项。优先完成FFT/功率谱，再根据数据量瓶颈决定下变频、滤波、抽取等模块是否迁入PL。AI仍保留I/Q信息支路，功率统计使用归一化前的数据。新增采样计数、溢出/丢块检测，使连续性和性能结论有实际依据。

依次完成浮点/定点参考、自检仿真、综合布局布线、跨时钟/接口约束审核、可回退部署和板端逐点比对。用同一输入比较改进前后的吞吐、延迟和CPU占用；CPU少算了一段不等于系统整体实时性已提高。

**交付/验收：**RTL/IP工程、测试向量、数值误差、资源/时序/CDC报告、实板数据和系统性能报告。ARM上的FFT不能冒充PL FFT。涉及合并硬件只能走已验证的受控启动路径，不热卸载ADC驱动或运行中重载PL。

### W7：可选实际通信应用

在测试系统稳定后选择一个具体用途，例如遥测数据或已知数据包传输。先实现帧结构、同步、解调、校验和包序号，再统计误码率/丢包率。要有真实恢复出的有效载荷，不能用“AI认出了QPSK”替代“通信成功”。复杂调制和双通道应用根据实际需求再安排。

## 6. 每次继续工作的固定方法

1. 读START-HERE、最新交接、本计划和所选任务的原始证据，确认其他任务是否占用设备。
2. 选择最前面未验收且前置条件齐全的一项；本计划刚建立时，先整理W0并推进W1候选审核，W2作器件准备，W3可离线并行。
3. 实板步骤前只读核对实际身份、boot、当前进程与配置；单一任务持有串口和RX上下文。不能根据本文件中的历史状态直接发射或重启。
4. 小步实现并运行必要验证；每个阶段先声明验收口径。失败保留原始证据，修复后复测受影响部分。
5. 新增实验记录，更新任务状态与最新交接。记录已做、失败、未做、硬件终态和准确下一步，不用百分比替代验收。
6. 停工前停止受控收发、确认清理并释放串口，归档RAM中需要保留的数据。是否正常关机以实际操作记录为准；新检查点不得覆盖旧检查点。
