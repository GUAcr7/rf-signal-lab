# P05a-2：频谱排成时间地图——瀑布图

## 本轮要做的东西

一条频谱只能说明一小段样本里的频率分布。把连续位置的样本分别算成频谱，一行接一行排起来，就能观察“频率在什么时刻出现或移动”。横轴是基带频率，纵轴是样本对应的时间，颜色表示功率强弱。持续单音成为竖线，改变频率后竖线移到别处。

瀑布图也常叫时频图或谱图。本任务复用 P05a-1 的功率频谱函数，不另定一个功率尺度。

## 分帧与重叠：像移动一扇小窗

假设每次看 N 个样本，然后把小窗向前移动 H 个样本：

- N 是每行 FFT 的样本数；频点间距为 fs/N。
- H 是步长；H=N 表示前后窗口刚好接上。
- H=N/2 表示两次观察有一半样本重复。重复观察不等于重复采到了新数据，增加行数也不代表独立数据变多。
- 时间行间距为 H/fs，每行实际观察时长为 N/fs。更密的行间距不代表能分辨任意更短的事件。
- 本参考不允许 H>N，避免悄悄跳过中间样本。尾部不足 N 点则不补造数据，而是报告剩余点数。

时间约定：从文件第 0 个样本开始计时；每行位置取该窗首末样本位置的平均值 `(start+(N-1)/2)/fs`。这是样本时间，不是电脑画图或收文件的时间，也不是硬件提供的绝对时间戳。

某一窗跨越变频边界时，里面包含前后两种频率，出现过渡是正常现象。本实验只把完全落在一个已知频率区间的窗用于逐行频率验收。

## 防止图越运行越占内存

历史缓存像一个只能放固定数量卡片的盒子。盒子满了，再放入新频谱时，最旧一行移出。记录移出次数；这叫显示历史淘汰，不能称为 ADC 丢样。

本小任务建立最多 96 行的示例缓存。全量离线时频数组另外保存，不因显示缓存淘汰而丢失。频率轴/采样配置变化时需建立匹配的新缓存，不能把两种坐标混到一起。

## 实现前固定的预期

仿真输入总长 98,304 点，fs=1,024,000 Hz。前 32 ms 为 -128 kHz，中间 32 ms 为 +128 kHz，最后 32 ms 为 +256 kHz，幅度 0.5，连续相位，无添加噪声。它是测试信号，不是实际发射。

每行 N=1024、H=512、周期 Hann 窗，因此：

1. 频点间距 1 kHz，行时间间距 0.5 ms，每行观察 1 ms。
2. 行数是 `floor((98,304-1024)/512)+1=191`，没有不足一窗的尾部。
3. 189 个完全处于单频率区间的窗，每行最大频点应等于该区间已知频率；2 个跨边界窗口单独标记，不强求单峰。
4. 输入幅度始终为 0.5，因此每行 PSD 积分应为 0.25，包括跨变频边界的行。
5. 96 行缓存最终保存最后 96 行，淘汰 95 行，时间顺序保持一致；清空后可从新的时间起点重放。

真实数据复用 2026-10-03 的 P02 文件，1024 点、fs=30.72 MS/s。用 N=256、H=128 可得 7 行，间距约 4.167 微秒，频点间距 120 kHz。只是同一短片段的重复窗口观察；不拼接两次独立采集，不复制旧样本冒充持续更新，不标注已知调制类别。
