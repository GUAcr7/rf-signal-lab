## 左上I/Q

- I、Q：AD9361下变频与采样后的复数信号两路分量，I为同相，Q为正交；不是两种不同调制类型。
- first 64 samples：本次只画前64组I/Q数据，是较短时域片段，不是整个信号记录。
- counts：数字采样计数，尚未换算为伏特。
- +/-338：这一幅图按前64组数据的最大绝对值采用约±338的纵向绘图范围；范围会随数据改变，不是ADC满量程规格。
- I blue Q orange：I为蓝/青色，Q为橙色。
- 2.051 us：第一点到第64点的时间间隔，63/30.72MHz约2.051微秒。不是GUI更新时间，也不是完整一次采集的时长。

短窗口中QPSK也可能显示近似正弦片段；不能仅凭这两条曲线判断调制类别。

## 右上频谱

- Spectrum：该来源数据计算出的数字频谱，各位置的高低表示对应频偏处的数字谱功率。
- dB re 1 count^2/bin：每个FFT频点相对1 count²的对数功率，约为10log10(该频点功率/1 count²)。不是dBm，也不是每Hz功率谱密度。
- -15.36 .. +15.33 MHz：横轴相对接收本振的频率偏移；30.72MS/s、1024点FFT，频点间隔30kHz，末端正频点为15.33MHz。
- -20 .. 70 dB：本图固定的数字功率纵向显示范围。频谱中多个尖峰不自动证明多个信号源，也不应仅凭照片断言是某种干扰或显示伪影。

## 左下瀑布图

- Waterfall: displayed snapshots：按先后叠加实际显示过的频谱快照，用来观察频谱随显示更新的变化。
- 横向为频率，颜色为数字谱功率，亮色通常更强；竖向为快照先后顺序。
- older top / newest bottom：旧快照在上，新快照从下方加入。
- gaps unknown：硬件采样块之间是否连续尚未证明；不能把竖向当无间断ADC时间轴。
- fixed colour -20..70 dB：固定颜色对应范围，与频谱数字功率范围相同，避免自动色标把强弱变化掩盖。
- 96 rows：最多保留96条已显示频谱快照，不是96秒，也不是96个ADC采样点。

- AI: BPSK / QPSK / 16QAM：模型对当前数据给出的支持类别；当前照片的类别文字被手机水印挡住，不能仅从照片读出。
- 85.7 ms：本次AI处理链的软件计时，包含策略、前端处理和CNN相关计算；不是整个屏幕刷新周期、点击到识别的端到端时延，也不是纯粹网络一次前向的独立计时。

## 发送控制小屏

| 字段/按钮 | 意义 |
|---|---|
| RF SOURCE | 射频信号源控制界面标题。 |
| IDLE | 发射控制当前空闲，没有正在执行的发射任务；新板接收程序可以继续运行。 |
| TONE | 单音参考/测试。现有流程主要用作准备阶段校准，校准后按既定三类演示，不把它当第四个AI分类类别。 |
| BPSK | 二进制相移键控，两种符号相位状态，通常每符号1比特。 |
| QPSK | 四相相移键控，四种符号相位状态，通常每符号2比特。 |
| 16QAM | 16阶正交幅度调制，16种星座状态，通常每符号4比特。 |
| SEL QPSK | 已选择QPSK；只表示源端选择，不是接收端AI结果，不表示已经开始发射。 |
| DUR 15 s | 当前请求每次发射15秒；从实际发射开始计时，检查等待不算有效发射时长。 |
| - / + | 每次减/加5秒，在8–60秒范围内限制。修改时长使原APPLY失效，需要重新确认。 |
| APPLY | 检查并确认当前类型、时长、波形和收发状态；通过后显示READY，此时还没开始发射。 |
| START | READY后请求实际限时发射；先STARTING，收到原生发射回执后才显示RUNNING。 |
| STOP | 请求结束当前发射，等待原生清理后回IDLE；不会自动关闭新板的接收程序。 |

常见状态：CHECKING为检查中，READY为可开始，STARTING为启动中，RUNNING为正在发射，STOPPING为正在结束及清理，FAULT为异常拒绝继续，OFFLINE为控制服务已结束/未连接。验收窗口结束或全部条件完成后，服务可主动关闭并显示OFFLINE。

正常操作：选信号并看SEL改变 → APPLY → READY → START → RUNNING。每次改变类型或时长都重新APPLY。要证明主动STOP，必须在RUNNING期间按，不把自然到时结束当成按键停止。

## 简短解说顺序

先介绍小屏选择和启动，再指大屏：顶部看持续更新；左上看I/Q；右上看频谱；左下看瀑布图；右下读中心频率估计、区域带宽和相对背景功率；最后读底部AI类别。拍摄时避开手机水印、反光，确保类别、单位、READY/RUNNING等文字清楚。
