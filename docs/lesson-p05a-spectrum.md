# P05a-1：把保存的 I/Q 变成有正确坐标和尺度的频谱

本小任务只做离线频谱参考；不配置板卡，不执行发射，不做实时界面、瀑布图或调制识别。

## 先用直观语言理解

时域图像一段录音的波形，显示每个时刻的数值。频谱像把这段录音拆开，显示里面哪些“音高”较强。这里的“音高”对应无线信号的频率变化，FFT 是完成拆分的一种高效计算方法。

AD9361 已将射频搬到基带。保存的 I/Q 是 `I+jQ` 两个数配合描述的信号，频谱因此保留负频率和正频率：它们表示在接收调谐频率的下侧和上侧。不是只画 I 的频谱，也不把负半边折到正半边。

例如调谐到 2.4 GHz，基带 +0.96 MHz 理论上对应 2.40096 GHz。真实链路的方向还需要 P03 已知射频输入验证；仅软件坐标计算正确不代表物理方向已经验证。

## 截一小段数据会带来什么

FFT 使用有限的 N 个样本，相当于只截取一小段录音。截取位置不合适时，一个频率会扩散到旁边，这叫频谱泄漏。窗函数让两端逐渐变轻，减弱远处扩散，同时让主峰变宽。

本参考明确支持矩形窗（每点权重 1）和周期 Hann 窗：`w[n]=0.5-0.5*cos(2*pi*n/N)`。周期形式用于本次频谱，与 P04 图里 `np.hanning(N)` 的对称形式不同，不能只凭峰高比较两张图。

频点间距 `Δf=fs/N`；fs 是采样率。30.72 MS/s 下 1024 点的间距是 30 kHz，样本对应的时长约 33.33 微秒。它不等于真实仪器能分开任意相邻两信号的能力，窗函数也会影响分辨能力。

## 功率尺度为什么要约定

I/Q 数值变成原来的两倍，`I²+Q²` 就变成四倍。功率变化用 `10*log10(4)` 表示，约 +6.0206 dB。

本参考令 `X=FFT(x*w)`，功率谱密度 `PSD[k]=|X[k]|²/(fs*sum(w²))`。每频点功率为 `PSD*Δf`，积分是各频点功率之和。没有去均值、去噪、归一化输入、补零或截短输入。

- 矩形窗积分应等于原始时域平均 `mean(|x|²)`。
- Hann 窗积分应等于窗加权平均 `sum(|x|²*w²)/sum(w²)`。对变化幅度的数据，它不一定等于未加窗平均，两个值都记录。
- 真实保存数据的数值是 ADC 数字计数，因此 PSD 单位为计数平方/Hz。显示的 dB 明确参考 1 计数平方/Hz，不是 dBm 或 dBFS。
- 用谱中最大频点报告“峰位置”，不把它称为本项目 P05b 所定义的中心频率估计。

## 运行前固定的理论预期

1. `fs=30,720,000 Hz`、`N=1024`、幅度 0.5 的 +960,000 Hz 单音，峰在 +960,000 Hz（未移位 FFT 的第 32 号频点）。总数字功率应为 0.25。
2. 相同单音改成 -960,000 Hz，峰应在负侧；频点间距仍为 30,000 Hz。
3. 矩形窗下理想对齐单音的功率集中于一个频点；周期 Hann 窗下中心与左右相邻频点各占总功率的 2/3、1/6、1/6。不能要求两窗峰高相等。
4. 输入幅度乘 2，每频点功率和总功率乘 4，相对增加约 6.0206 dB。
5. 零输入得到全零线性 PSD，没有“有效信号峰”；绘图的负 dB 下限只是显示限制，不修改保存的线性数据。
6. 同一采样文件重新分析应得到相同数组；未知真实输入的峰位置不预先指定，也不能据此标出调制类别。
