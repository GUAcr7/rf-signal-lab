# 第二课：把 BPSK 约定写成 Python 黄金参考模型

本课只完成一件事：把比特 `0/1` 映射为 BPSK 符号系数 `+1/-1`。此时还没有时间轴、载波或连续波形。

## 1. 先写清输入和输出

- 输入：一维、非空的 0/1 序列，例如 `[1, 0, 0, 1]`。
- 输出：同样长度的浮点数组；本项目约定 `0 -> +1.0`，`1 -> -1.0`。
- 错误输入：空序列、二维排列或含有 0/1 以外的值，函数应明确报错。

这里的 `+1/-1` 是“选择哪种相位”的符号系数，不是已经按时间采样的载波波形。

## 2. 黄金参考代码

核心表达式在 `src/rfsig/bpsk.py`：

```python
return np.where(bit_array == 0, 1.0, -1.0)
```

直观地读：逐个查看输入；如果当前位置是 0，就在相同位置放 `+1.0`，否则放 `-1.0`。

`np.asarray(bits)` 把 Python 列表转换成 NumPy 数组，方便后面统一进行波形计算。`ndim` 表示数组有几个方向：`[1, 0]` 是一维，`[[1, 0], [0, 1]]` 是二维。输入检查可以阻止错误数据悄悄产生一个看似正常的结果。

## 3. 在运行代码前确定理论预期

对于 `[1, 0, 0, 1]`，根据约定逐项手算：

```text
输入比特：  1    0    0    1
理论输出： -1   +1   +1   -1
```

因此完整预期数组是 `[-1.0, 1.0, 1.0, -1.0]`。这个预期直接来自映射表，不来自待测试的 Python 函数。

## 4. 单元测试在检查什么

单元测试是自动执行的小型检查。本课测试包含：手算序列、全 0、全 1、交替序列，以及空输入、非法值和二维输入。

最重要的断言是：

```python
np.testing.assert_array_equal(actual, expected)
```

它逐个比较实际数组和预期数组。这里的结果只有精确的 `+1/-1`，不需要误差容限；以后测试正弦波和 FFT 浮点运算时才会讲误差容限。
