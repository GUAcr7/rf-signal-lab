# P05c：先证明滤波保留了有用信号

本轮只处理已保存的 P04 仿真波形，不连接板卡，不打开界面，不用未知射频数据设计滤波器。

## 1. FIR 做了什么

设输入是复数 I/Q，滤波器有 M 个实数系数。输出为

`y[n] = h[0]x[n] + h[1]x[n-1] + ... + h[M-1]x[n-M+1]`。

“抽头”就是这里的一项系数。I 和 Q 分别乘相同系数再相加，仍保留复数信息。不同频率经过这组加权后衰减不同。本次做低通：保留零频附近的目标信号，减弱较远的带外成分。

通带是要求尽量保持幅度的范围；阻带是要求明显衰减的范围；两者之间是过渡带。有限数量的系数不能造出没有过渡的理想砖墙。窗函数法是一种生成有限系数的办法，本次用 Hamming 窗截断理想 sinc，并令系数和为 1，使直流增益为 1。[SciPy 官方窗函数 FIR 说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.firwin.html)

## 2. 先规定本次指标

P04 三类波形均为 Fs=1 MS/s、Rs=125 ksym/s、RRC 滚降 0.35。理想单侧支持范围是 `(1+0.35)*125000/2 = 84375 Hz`；有限 RRC 截断会有带外残留。这个公式不是 99% 占用带宽的答案，也不是板卡当前的配置。

| 内容 | 实验前规定 |
| --- | --- |
| 适用输入 | 居中、Fs=1 MS/s 的 P04 完整离线记录 |
| 通带 | \|f\| ≤ 100 kHz，最大幅度增益偏差 ≤ 0.1 dB，峰峰纹波也 ≤ 0.1 dB |
| 阻带 | 200 kHz ≤ \|f\| ≤ 500 kHz，衰减 ≥ 50 dB |
| 初选系数 | 63 抽头、对称 Hamming 窗、sinc 截止 150 kHz、DC 单位增益 |
| 波形保留 | 仅补偿已知整数延迟，三类相对 RMS 波形误差各 ≤ 1% |
| 完整性 | 分块结果加末尾等同全卷积；保存后逐点回读一致 |

这里的 150 kHz 是设计截止点，约为半幅度（-6 dB），不是通带边缘或 -3 dB 点。若初选长度不满足预定指标，应增加抽头并记录原因，不事后放宽指标。

最大偏差比较相对 0 dB 的偏离；峰峰纹波是通带中最高与最低增益的差。本轮两者都记录并验收。频响按稠密数值网格并加入精确边缘检查，报告不会把有限网格验证称作连续频率极值的解析证明。

阻带衰减 50 dB 的含义是：稳态正弦振幅比不超过 `10^(-50/20)`，约 0.003162；同一频率的功率比不超过 `10^(-50/10)`，即十万分之一。它不表示所有条件下的接收 SNR 都会提高 50 dB。

## 3. 延迟、开头和结尾

63 抽头对称线性相位 FIR 的群延迟是 `(63-1)/2 = 31` 个样本，在 1 MS/s 下为 31 µs。实时处理不能凭空消除这段因果延迟；离线比较时可以按已知延迟对齐。

长 N 点的完整有限输入会得到 N+62 点输出，假定输入记录之外为零。不要用 `same` 模式悄悄裁掉边界，也不要把末尾丢掉再说完全一致。[NumPy 全卷积说明](https://numpy.org/doc/stable/reference/generated/numpy.convolve.html)

本次波形误差比较 `y[31:31+N]` 与原输入 x，计算 `sqrt(sum(abs(y_aligned-x)^2)/sum(abs(x)^2))`。不另行拟合增益/相位，也不重新归一化来掩盖改变。这是有限离线波形的相对 RMS 误差，**不是同步后的符号 EVM、误码率或 AI 准确率**。完整输出尾巴另行保存。

## 4. 为什么分块必须带状态

如果输入确实连续，下一块开头还要用上一块最后 M-1 个输入点。每块都清零会产生额外边界跳变。`FirStream.process` 保留历史，每次返回与输入同长的因果输出，最后 `finish` 输出剩下 M-1 点，`reset` 才开始独立新记录。[滤波初始与最终状态说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.lfilter.html)

当前真实监测文件的块间连续性未知，不能把这批 IIO 快照当作一条连续波形送进有状态滤波器。本轮仅用连续的 P04 离线记录验证分块参考，尚未接入实时接收窗口。

## 5. 本轮的检验方式

1. 扫描完整正频网格，并在通带/阻带边缘明确取值；负频由实系数共轭对称性检查，抽样直接求频率响应以核对 FFT 计算。
2. 给入正负 50 kHz 与正负 300 kHz 单音，避开启动过渡，检验幅度、相位和功率与解析频响一致。
3. 对三份原 P04 波形分别滤波、对齐、测误差；再给其中一份加入已知 300 kHz 干扰，分别记录目标改变和干扰衰减，不把混合波形的整体功率降低说成目标增强。
4. 以手算短卷积、不同块切分、脉冲、固定直流与输入错误检查实现；保存系数、输入/完整输出/对齐输出和配置，再独立回读。

本轮完成的是浮点黄金参考。是否最终需要新增 PL FIR，要结合受控 RF 目标频带、频偏余量和 AD9361 已有滤波确定；这套离线系数不能直接用于 Fs=30.72 MS/s 的板卡输入。FPGA 定点参考、TestBench、资源/时序/吞吐和真实上板另在 P07 验收。本次不涉及模型训练，AI 数据集/准确率/量化指标不适用。
