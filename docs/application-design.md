# Zynq 的信号AI识别系统 应用设计

## 使用目标

工厂部署无线传感器、演出现场部署无线音视频设备时，需要了解候选信道的占用和干扰情况；通信丢包或连接不稳时，也需要判断应先检查目标信号强弱还是额外占用。

现场选信道的设计用法是先观察候选频段的背景与占用，再在相同接收设置和参考发射条件下比较目标信号的可辨识程度与稳定性。通信排障则对照目标信号、频谱和背景的变化，形成衰减、干扰或设备设置方面的排查线索。以上场景是目标用途，已有实测为固定配置的受控有线实验。

## 参数解释

采用 ROI 中心、99% ROI 带宽、数字功率、相对背景指标和频谱随时间的变化进行对照。比较须固定增益、采样率、滤波与 FFT 设置、观察区域和参考条件。界面的 Above background 是同配置下 ROI 与背景参考的比值，不能直接当作已标定 SNR。没有参考目标的空闲信道也不能按目标 SNR 排序。

目标变弱或出现额外频谱成分只能提供排查线索。距离、遮挡、天线、增益、谐波和接收机失真等因素均可能影响观察结果，具体原因还需现场对照确认。阈值、自动评分和跨频段能力留待后续实现与独立验证。

## 测试结果的对应范围

原冻结 INT8 流程在 54 帧独立真实 RF 测试中正确 52 帧，准确率 96.30%。后续固定八相位策略改变了推理流程，演示回归成绩单列。ARM 算法链约 22.46–22.55 ms/块，不含采集、文件 I/O、绘图与显示刷新。上述结果均不作为信道质量评分或现场故障定位的准确率。
