# P05b-2：99% 占用带宽与谱中心

先把频谱想成沿频率摆放的一排装水的杯子，每杯里的水量代表该频率附近的功率。从低频向高频加起来，找到总水量的 0.5% 和 99.5% 所在位置，两点之间就容纳了中间 99% 的功率。两点之差是 99% 占用带宽，中点是本项目约定的谱中心。

公式：`B99=f_high-f_low`，`f_center_base=(f_low+f_high)/2`。若接收调谐频率是 f_LO，则显示 `f_center_RF=f_LO+f_center_base`。物理方向还需已知 RF 验证；不把调谐设置或最大谱峰直接叫测得中心。

## 先明确算哪一段频率

调用必须给出分析频段，只计算它包含的谱功率。选择的频段应完整包含一个目标；若它截掉信号，带宽就会偏小。把多个信号一起框入时，中点只是这个总分布的中点，不保证对应任何一个载波。

噪声也有功率。未知环境输入算出来的结果可能主要反映噪声和接收滤波带宽，因此本函数不声称检测到了通信信号。真实旧样本默认不减噪，不猜噪声底，结果标为“选定频段的谱分布”，目标物理参数待验证。

参考允许显式提供一个已知的常数噪声 PSD，按 `max(PSD-floor,0)` 扣除；必须记录取得方法。默认值为 0 表示不扣除。设置最小有效积分功率可返回“低于阈值”；零有效功率返回“无有效功率”，各边界/带宽/中心为 null。这个检查不等于完成了通信信号检测或 UNKNOWN 分类。

## 本次频点内部怎样算

每个 FFT 点的 PSD 在该频点左右各半个频点间距内按常数处理；分析频段切到半个杯子时，仅按实际覆盖的频宽积分。累计边界在杯子内线性插值。

这是明确的数值参考约定，不是亚频点精度的硬件测量证明。FFT 频点间距、窗函数主瓣、有限观察时长、噪声和频率基准都会影响真实误差。本参考与其他工具的边界插值规则可能不同，不声称与 MATLAB 输出逐位相同。

首/尾频点的半格边缘涉及 FFT 周期边界。本项目分析频段保持在奈奎斯特区间内部，不用于跨越采样边界的环绕目标。真实默认分析 -9 至 +9 MHz，配合旧记录 fs=30.72 MS/s、RF BW=18 MHz；这只是分析范围，不是测量答案。

## 运行前独立预期

1. 0～10 Hz 内均匀 PSD=1，边界 0.05/9.95 Hz，带宽 9.9 Hz，谱中心 5 Hz，积分功率 10。
2. 同一均匀谱只分析 2.25～7.75 Hz，边界 2.2775/7.7225 Hz，带宽 5.445 Hz，中心仍为 5 Hz。
3. 三个 1 Hz 格子功率为 0.5/99/0.5，总 100，边界恰在中间格子的两侧，带宽 1 Hz。
4. 只把全部功率乘正数，不改变边界；把频率轴整体加一个偏移，边界/中心同样移动，带宽不变。
5. 给均匀谱加已知均匀噪声，再扣除同一噪声底，应恢复原结果；扣除后全零应返回明确无有效功率状态。
6. 幅度 0.5、对齐 FFT 频点的单音，周期 Hann 频谱占 3 个频点，其 99% 范围由该窗决定，不能说理想单音的实际物理带宽等于这个数字。
7. 同一 P04 波形用全部样本与短窗分别估计，有限帧结果会变化，必须记录窗/点数。RRC 的理想总支撑宽度 168.75 kHz 不是 99% 带宽的理论答案。
