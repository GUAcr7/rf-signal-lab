# 无频谱仪的功能演示操作卡

用途：按用户要求，先演示已验收的真实收发、板端三类识别、四区显示及屏控启停。此演示依赖本地电脑中转控制，无需互联网；不包含频谱仪测量对照，不声称绝对频率/功率标定、未知信号通用识别或整机脱离电脑运行。最终视频时长和提交方式以赛事提交通知为准。

## 由 AI 完成准备

确认旧 P201 TX1 → 原衰减连接 → 新 TLZ7xH RX1A，TX2 与频谱仪不接入。每次新接收会话重新准备背景和固定参考单音校准，核对同一 boot、源包 SHA、接收进度/型号/模型与清理状态，再启动 P80 快速屏控。屏幕状态 IDLE 后才进行人工演示。

## 人工按键与镜头顺序

1. 全景拍清旧板、新板、小屏、原衰减连接和电脑，说明电脑用于控制及校准，接收分析/识别/显示在新板 ARM 运行。FPGA 逻辑的作用按实际工程另行说明，不将 ARM 推理说成 PL 加速。
2. BPSK → APPLY → 等 READY → START → 等 RUNNING。镜头拍新板顶部序号更新、四区画面和识别结果；默认 15 秒自动回 IDLE。
3. QPSK 和 16QAM 分别重复上述流程，每次等上次回 IDLE 再选择下一种。选择变化会使旧 APPLY 失效，需重新 APPLY。
4. 再启动一次任意上述调制，在旧屏实际显示 RUNNING 时点 STOP，拍其回 IDLE，以及新板随后显示无有效信号/不再保持有效分类。STOP 回 IDLE 与接收界面的 RX STOPPED 是不同状态：前者停止旧板发射，后者停止整个接收程序。
5. 完成后告诉 AI，由其停止接收并保存日志、I/Q 和截图。控制服务结束后旧屏 OFFLINE、新板 RX STOPPED 均为正常收尾，不代表断电或故障。

## 等待与说明

依据 P81 实测，APPLY 和 START 通常各需数秒；先看状态再按下一键，不在 CHECKING/STARTING 期间连续点。15 秒从真正开始发射算起，启动检查不计入有效发射时长。进入 FAULT 时停止操作并报告，不通过反复点 START 绕过。

新板每次接收上限仍为 15 分钟。期间显示更新次数/来源块序号，不将它们称为连续 ADC 帧率或无丢样证明。没有发射时显示背景/NO_USABLE_SIGNAL，属于正常现象。所有识别结论限定于当前受控三类及验收范围。

本操作卡仅说明流程；本轮完成与否以当次原始按键、原生任务回执、完整接收历史和用户目视反馈为准，不以操作卡替代实验记录。
