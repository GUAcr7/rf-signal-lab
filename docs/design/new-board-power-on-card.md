## 1. 七步接线（严格按顺序，前六步全在**断电**状态下做）

> 全程：**电源开关在 OFF、12V 未接入**。不要带电插拔排线、FMC 模块或 SD 卡。

### ① 插 Micro SD 启动卡

- 位置：板子**下边缘偏右**的金属卡槽，旁边丝印竖着写 `Micro SD`。
- 动作：卡的金手指**朝向板内**，推到底听到"咔"一声。
- **前提**：这张卡必须是创龙配套的 Linux 启动卡。**没有卡就无法启动**（见第 4 节）。

### ② 设启动拨码为 `101001`

- 位置：板子**右下角**，红色 6 位拨码开关，丝印 `ON` 与 `1 2 3 4 5 6`。
- 手册要求：`101001`（位 1~6），**ON = 1，OFF = 0**。
  即 **1、3、6 = ON；2、4、5 = OFF**。
- **验收方式**：拨完**拍一张这个开关的正面照片**发我，我按图核对每个拨片方向。
  **不要凭猜测判断 ON 方向** —— 不同批次丝印方向可能相反，按图核对最保险。

### ③ 接调试串口到电脑

- 位置：板子上边缘偏右的 **Micro USB** 口，丝印 `USB TO UART`（旁边是黑色双排 `JTAG` 座）。
- 用普通 Micro USB 数据线接电脑，**不是充电线**（充电线常常没有数据线芯）。
- 这是 **PS 端调试串口**，是唯一能看到启动日志的口。

### ④ 接屏幕排线（可跳过）

- 位置：板子中部 `ZYNQ` 丝印正下方的**白色 40pin FFC 座**，旁边丝印 `RES LCD`。
- 另一端接 `TL-70RESLCD-B2` 转接板的 **CON2**（白色宽排线座）。
- 排线**金手指朝向**按座子上的指示，翻盖压平锁紧。
- **第一次开机建议先不接**：少一个变量，先把系统启动跑通。屏幕留到阶段 2 再验证。

### ⑤ 插 AD9361 模块（**第一次强烈建议跳过**）

- 位置：板子**右侧**的长条黑色高密度连接器，丝印 `FMC`（400pin HPC）。
- 模块对准、**平推压入**，检查两侧卡扣都到位。
- **第一次开机不要插**。原因：模块会增加供电负担，且一旦启动异常无法判断是主板还是模块的问题。
- **安全前提**：模块是 AD9361，RF 输入绝对最大 **+2.5 dBm peak**，**任何情况下不要把它接到未经核算的发射源**。

### ⑥ 接 12V 电源

- 位置：板子**右上角**的黑色圆筒插座（DC-005），上方是红色电源开关。
- 插头规格：**外径 5.5 mm / 内径 2.1 mm**，中心正极。
- **电压必须是 12V DC**。
- ⚠️ **资料内部对电流标注不一致**：规格书写 `12V 6A`，硬件说明书与资源图写 `12V 3A`。
  **处理办法**：用配套适配器；看适配器标签，只要 **12V 且 ≥3A** 就可以（电流是"能供多少"，大于需求无妨）。**电压绝不能高于 12V。**
- 板上有过流过压保护，但不要依赖它。

### ⑦ 开机

- 把红色电源开关拨到 **ON**。
- 预期现象：板上 LED 亮；**核心板 LED 有规律闪烁** = 系统启动正常（手册原文）。
- 若 **5 秒内没有任何 LED 反应**：立刻拨回 OFF 并拔掉 12V，告诉我。

## 3. 开机后我会做什么（全部只读）

1. 抓启动日志，确认 U-Boot 与 Linux 版本（资料配 Linux-4.9.0）
2. `uname -a`、`cat /proc/cpuinfo`（确认双核 A9）
3. `cat /proc/device-tree/model`（确认板型字符串）
4. `ls /sys/class/net`、`free -m`、`df -h`
5. **不烧写、不写 flash、不改拨码、不动 PL**

## 4. 启动卡：已确认在位且正在使用

实测 `root=/dev/mmcblk0p2`，而 `mmcblk0` 的 `device/type` 是 **`SD`**，`mmcblk1` 是 `MMC`（eMMC）。
**说明系统正跑在随板 SD 卡上，不需要自制启动卡。**

自制卡的风险（需要 `mksdboot_11_21_24_21.tar.gz`、会擦除整张卡、2017 年工具在新系统上未必能跑）**本轮完全不需要承担**。
