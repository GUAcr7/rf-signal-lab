# 下一阶段：定位实际16QAM不确定块

## 已知事实

P70生产短流程稳定窗口16QAM只有7/12次被接受，另外5次不确定；已接受标签均正确。三帧预测常为[2,2,0]或[2,1,2]，被原一致性策略拒绝。完整历史复核否定“只是轮询抽样误差”。指标仍有效，内核、收发资源清理和显示正常。

P71对旧成功快照做±1000Hz频差和0～112样本偏移，未复现16QAM拒判；QPSK成功快照反而有敏感情况。**尚无证据证明根因是频漂、定时或模型本身**。不调整已冻结模型，不改成2/3投票，也不延长窗口后掩盖原失败。

## 按依赖执行

1. 重新只读认板，保持现有P70/模型/PHY参数，验证旧板源关闭及当前boot源包SHA。先保存完整原状态。
2. 建立新会话，采当前背景/单音。采用同一已验证16QAM、峰值256/−10dB，不改发射强度或接收增益。预先固定“校准后早期”和“同一次校准后较晚”的有限时采集窗口，调查校准年龄，不能根据看到的分类再选评分区间。
3. 同时保留固定间隔快照及不确定触发快照。原生shot至多16个；每个必须核对保存下来的AI状态/块号，不能把触发时的不确定误当成稍后保存的正常块。优先传I/Q+AI+指标，少量加显存，控制tar在16MiB上限内，不挑选掉失败样本。
4. 在电脑和冻结C前端/模型上逐块复现原始三帧预测、logits、功率、频偏及定时。先判断ARM/Python是否一致，再比较成功和失败块；如需估载波/相位，先用已知数学夹具验证估计器，不用真实类别或“分类最正确”反调频率。
5. 若复现出前端敏感性，建立独立候选分支，原P52/P56与P70可回退版本保留。若需训练，按原始波形/采集会话分组，划分训练/验证/新测试，冻结参数后再验收；不把暴露seed2315或P71探查数据当作新的独立成绩。
6. 最后按原稳定窗口、覆盖率≥70%、已接受正确率≥90%复测，并单列背景/单音/削顶/失校准的拒判；同时检查数字指标和停止清空。报告每个条件的最差情况，不能仅用总平均掩盖一次失败。

本计划是后续执行方案，不是已定位根因或已修复的证明。冷启动/十分钟显示已由P71验证；没有相关改动时无需反复重做整套显示实验。
