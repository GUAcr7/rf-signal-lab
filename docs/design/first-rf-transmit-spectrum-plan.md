## 0. 先回答"要不要衰减器"

**本机仪器已实测确认**（用户 2026-10-16 16:51 拍摄的仪器面板照片）：频谱分析仪 `RF Input 50Ω` 标注 **`+30 dBm / 50 VDC Max`**，另有独立的 `Gen Output 50Ω 50 VDC Max`（跟踪源输出，本轮**不使用**，不要把发射信号接到 Gen Output）。

| 场景 | 要不要衰减器 | 理由 |
|---|---|---|
| P201 TX → **本频谱分析仪** | **不需要**（有约 30 dB 余量的前提下） | 分析仪最大输入 **+30 dBm**；即使旧板 PA 增益取偏大的 25–30 dB，按 AD9361 在 −10 dB 衰减下最大约 +7 dBm 估算，TX 口峰值约 +32～+37 dBm 属于**偏保守的上界估计**，与 +30 dBm 同量级，因此**首测仍必须从最小输出开始**，见下方"安全启动条件" |
| P201 TX → **第二块板的 RX** | **必须要**，没有例外 | AD9361 的 RF 输入绝对最大值只有 **+2.5 dBm peak**，且本板 RX 路径无 LNA；同时旧板 TX 口输出上限在原厂手册中**没有给出** |
| P201 TX → 天线 | 本轮不做 | 涉及频谱合规，与本轮目的无关 |

### 安全启动条件（三条同时满足才允许第一次发射）

1. **先做 M1（零输出）**：程序在创建 DMA 前会把 DDS 全部置零，所以"不发射"状态下的输出只有本振泄漏（数据手册载波泄漏在 0 dB 衰减时约 −50 dBc，本板为 −10 dB 衰减）。先读到这个泄漏电平，才有基准。
2. **第一次发射时长不超过 3 秒**，数字波形沿用已交付的 `tone-positive.iq16le`（分量峰值 512，约为满量程 1/4）。
3. **分析仪先用最大内部衰减 + 参考电平 0 dBm** 粗看；若读数进入 +20 dBm 以上，**立即停止**并加衰减器复测。

**为什么仍不建议"闭眼直连"**：+30 dBm 是这台仪器的上限，而旧板 PA 增益在原厂手册中缺失，属于**未知量**。本方案把未知量限制在"从最小输出逐级看"的路径上，而不是用估算值直接赌上限。

**量程提醒**：+30 dBm 是**不损坏**的界限，不是**准确测量**的界限。多数分析仪在约 −20 dBm 以上就开始压缩，读数会偏低。所以看到强信号时要**增加内部衰减**再读，否则会把电平读小、误判为安全。

结论：**频谱分析仪是补上"旧板 TX 到底多少 dBm"这个缺失数据的工具**。先测出来，"需要多少衰减（给第二块板用）"就变成一道算术题。不要用估计值去凑。

## 1. 本轮唯一可用的发射配置（不动板卡任何设置）

发射程序 `arm-tx-source --run` 采用**失败即安全**：当前任一项射频设置与请求不完全一致，它**直接退出且不写任何配置**（源码 `arm_tx_source.c` 第 378–386 行）。因此本轮只能沿用它已经读过的那一组值：

| 参数 | 必须传入的值 | 来源 |
|---|---|---|
| 文件 | `waveforms/existing30m72/tone-positive.iq16le` | 交付包；sha256 `36cd4ed7007721dd023b7b2c8b581a5ddb6f0365d9c0c0a40fef7c87522a0727`（本次已在电脑上复核一致，524288 B） |
| 样本数 | `131072` | manifest |
| 采样率 | `30720000` | 板端只读读回 |
| TX LO | `2450000000` | 板端只读读回 |
| TX 带宽 | `18000000` | 板端只读读回 |
| TX 增益 | `-10` | 板端只读读回 |
| 端口 | `A` | 板端只读读回 |
| 时长 | 首次 `3` 秒（上限 60 秒） | 本方案 |

该单音的**数字偏移是 +960 kHz**，所以频谱分析仪上应出现在：

```
f_tone = 2450000000 + 960000 = 2450960000 Hz  = 2.45096 GHz
```

同时**必然**存在一个**本振泄漏**分量，位置在：

```
f_LO_leak = 2450000000 Hz = 2.45 GHz
```

本振泄漏与数字内容无关；程序在 DMA 前把 DDS 全部置零，所以泄漏不是 DDS 产生的。

**方法学提醒**：`2.450960 GHz` 的峰是真正的**调制信号**；`2.450000 GHz` 的峰是**载波泄漏**。两者只差 960 kHz，测的时候务必把 RBW 调小（例如 10 kHz）以分辨，否则会把泄漏当成信号、或把信号幅度算错。

## 2. 接线与仪器设置（务必按顺序）

1. **先接仪器端**：把 50 Ω SMA 同轴线接到频谱分析仪的 RF INPUT，确认接头拧紧。
2. **仪器先设大内部衰减**：输入衰减打到最大（通常 20–30 dB），参考电平设高一点（例如 0 dBm），RBW 先用 100 kHz 粗看。
3. **再接板卡端**：线缆另一头接到 P201 的 **TX1** SMA。四口的物理排列见实物照片 `results/p03-antennas-board.jpg`（2026-09-28，四口都拧着黑色天线，从左到右）与 `results/p03-board-rf-ports.jpg`（2026-09-20，可见丝印小字与 FZ 天线座）；丝印对照表在 `results/p03-board-rf-ports.jpg` 的相邻位置。
   - 排列（横放、天线朝向远端时，**最左 = TX1**）：**TX1 – RX1 – RX2 – TX2**。
   - 因此**先拧下最左边那一根天线**，把频谱分析仪接到这个口。其余三口的天线保持原样。
   - 程序里 `tx0` 端口 `A` → **TX1** 属于**预期映射，尚未实测确认**；首次发射时用"哪个 SMA 出现信号"来反向确认，不要反过来假设。
   - 本次只使能 `voltage0`（也就是单路 TX0），未使能的 TX1 通道不输出数字内容；但**本振泄漏仍可能存在**，未接仪器的 TX2 保持原状即可。
   - 照片 hash 复核：`p03-board-rf-ports.jpg` = `67555bc17ffe1b66c46b085fa8c29d55a6d806e34c8f7b6d1b46fd9c72d536af`，与 [EXP-P03.md](../experiments/exp-p03.md) 记录一致。
4. **先做零输出基线**：在**不发射**的状态下先记录一次本底（此时 DDS scale 为 0，理论上只剩本振泄漏与环境噪声）。
5. **确认分析仪没有打开前置放大器**（如果有），并确认输入耦合为 AC。
6. 扫描范围先设 `2.40–2.50 GHz`，看到两个峰之后再收窄到 `2.448–2.453 GHz`。

## 3. 三次有序测量

按顺序做，每一次都记下数据再进入下一次。**任何一次出现"接近分析仪最大输入"的读数就立即停止，并加衰减器后再继续。**

### M1 — 本振泄漏（最安全，实际不发射样本）

目的：在最小输出条件下确认链路连通、并拿到泄漏量级。
做法：只让板卡处于已配置状态，不运行 `--run`。记录 2.45 GHz 处的电平。
记录项：`f_LO_leak`、电平(dBm)、分析仪输入衰减、RBW、VBW、扫描时间。

### M2 — 已知单音，3 秒

目的：拿到**真实发射电平**，这是决定衰减量的关键数字。
命令形状（由 AI 在串口执行，用户只需看仪器）：

```
cd /tmp/<新目录>/p201-source-.../ && ./bin/arm-tx-source --run \
  waveforms/existing30m72/tone-positive.iq16le 131072 \
  30720000 2450000000 18000000 -10 3 \
  <boot-session 身份> A \
  36cd4ed7007721dd023b7b2c8b581a5ddb6f0365d9c0c0a40fef7c87522a0727 RF_LINK_REVIEWED
```

记录项：**2.45096 GHz 处的峰值电平(dBm)**、2.45 GHz 泄漏电平、两者差值(dB)、发射是否在 3 秒后自动结束、结束后泄漏是否回落到 M1 的量级。

### M3 — 衰减/幅度线性核对（可选，视 M2 结果）

若 M2 得到的电平远低于分析仪上限，可把时长改成 5 秒复测一次，确认可重复性（同一设置两次读数差应很小）。
**本轮不改变 TX 增益**（改它就等于写射频参数，需要单独记录并重新走一遍守卫）。

## 4. 判定标准

| 观察 | 含义 | 下一步 |
|---|---|---|
| 两个峰都能稳定分辨，且 3 秒后自动停止 | 发射链路真实工作 | 记录数据，进入衰减量计算 |
| 只有 2.45 GHz 泄漏、没有 2.45096 GHz 峰 | 信号没到 PA/端口，或接错口 | 换到 TX2 试，并保留两次记录 |
| 峰很宽或大量杂散 | 可能削顶或 PA 非线性 | **立即停止**，先把输出降下来 |
| 接近分析仪最大输入 | 危险 | **立即停止**，加衰减器 |

## 5. 得到 M2 数字之后：衰减量计算

需要用户提供（届时由 AI 计算并写进记录）：

- `TX_peak`：M2 实测的 TX 口峰值电平（dBm）
- `ATTN_min`：衰减器最小衰减值与额定输入功率
- `CABLE_loss`：线缆在 2.45 GHz 的插入损耗（**有实测就用实测；没有就写"未知"，不用估计值抵消风险**）
- `RX_max`：第二块板 RX 口的推荐输入范围（原厂没给就必须继续查；**不得用 +2.5 dBm 芯片绝对最大值当推荐值**）

安全关系（沿用 [双板方案](../design/two-board-rf-link.md) 第 45 行的形式）：

```
RX_peak_upper = TX_peak - ATTN_min - CABLE_loss_min
```

并要求 `RX_peak_upper` 在 RX 推荐范围内、且衰减器额定输入大于 `TX_peak`。

## 6. 本轮明确不做的事

- 不把 TX 接到第二块板的 RX（没有衰减器、没有电平依据之前不接）。
- 不改板卡采样率/增益/本振/带宽/端口（首选方案完全不写射频参数）。
- 不改固件、不烧写、不动 FPGA 工程、不动设备树。
- 不接天线发射。
- 不把本轮读数当"功率已标定"：`-10 dB` 是**数字衰减读数**，不等于某个 dBm 值；真正的 dBm 只来自本次仪器测量。
