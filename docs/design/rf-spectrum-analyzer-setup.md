# RIGOL RSA3030（9 kHz–3 GHz）现场测量操作卡

用途：本项目的受控发射取证。目标是**让 Marker 停在主峰上**，并让照片同时记录频率、功率、仪器设置。
适用仪器：照片确认型号为 **RIGOL RSA3030**（Real-time Spectrum Analyzer，带跟踪源），`RF Input 50Ω +30 dBm / 50 VDC Max`。

> **原则**：判断信号靠"**比底噪高多少 dB**"和"**峰有多窄**"，不是靠绝对读数的绝对值。绝对 dBm 只有在 `Ref Level` 留足余量后才有意义。

## 0. 接线（最容易错的一步）

| 接口 | 用途 |
|---|---|
| **`RF Input 50Ω`** | **接板卡 TX1 的那根 SMA 线接这里** |
| `Gen Output 50Ω` | 跟踪源**输出**，**不要接**，接上去可能损坏板卡 |

## 1. 基础设置（每次上电后先做一遍）

| 按键 | 菜单 | 值 | 为什么 |
|---|---|---|---|
| `FREQ` | 中心频率 | **2.45 GHz** | 让 2.45000 与 2.45096 两个位置同时落在屏内 |
| `SPAN` | 扫宽 | **10 MHz** | 10 格 ÷ 10 MHz = **每格 1 MHz**，+960 kHz 的偏移正好在右侧约 1 格 |
| `BW` | RBW | **10 kHz** | 960 kHz 间隔必须分得开；RBW 太大两个峰会糊在一起 |
| `BW` | VBW | **≥ RBW**（如 10–30 kHz） | 抑制噪声抖动，读数更稳 |
| `AMPT` | Ref Level | **0 dBm** | 峰值约 −24 ~ −30 dBm 时会落在屏幕中部，**留约 10 dB 余量避免前端压缩** |
| `AMPT` | Atten | **20 dB**（先设这个） | 保护仪器；读数偏小无妨，确认有峰后再按需调整 |
| `Trace` | 迹线类型 | **最大保持（Max Hold）** | 发射只有几秒，Max Hold 会把峰"记住"，**发射结束后仍可慢慢读数拍照** |

**常见的错**：`Ref Level` 设成 −20 dBm 而峰值 −24 dBm（只差 4 dB）—— 迹线贴近顶端，前端可能已压缩，**读数会偏低**。所以本项目统一用 **0 dBm**。

## 2. 发信号并确认"看到了"

1. 让我在串口执行发射（通常 10 秒）。
2. 发射期间/之后看屏幕：**中心右侧约 1 格**应出现一个比底噪高得多、形状尖锐的峰。
3. 判定标准：

| 现象 | 结论 |
|---|---|
| 右侧出现比底噪高 **20 dB 以上**的窄峰 | ✅ 收到真实发射 |
| 只有中心那条细竖线，右侧没有峰 | ❌ 没收到 → 查端口（换 TX2）或线缆 |
| 整条曲线整体抬高几 dB，但没有尖峰 | ❌ 只是噪声波动 |

## 3. ⚠️ 中心那条"细竖线"不是信号

多次观察到的现象：屏幕**中心正好 2.45 GHz** 处有一条细竖线，而**真实白色迹线在该位置并没有抬高**。

这是 **Density 余辉/Max Hold 把一条显示竖线记住**的结果，不是射频信号。**`峰值搜索` 会优先跳到它上面，于是出现 `Mkr1 2.450000000 GHz` 这种误导读数。**

**排除方法**（任选其一）：

- 按 `Trace` → **迹线类型 = 常态（Normal）**，等 3–5 秒重新扫，竖线通常会消失；
- 或按 `Trace` → **清除保持 / Clear Hold**，清掉累积后重测；
- 或干脆按 `Marker → 右峰值`，**把 Marker 从竖线往右挪到真峰上**。

## 4. 让 Marker 停在主峰上（本次取证的核心）

**按键顺序**：

```
Marker  →  峰值搜索（Peak）
```

然后**看左上角**：

| 读数 | 判断 |
|---|---|
| `Mkr1 Freq : 2.4509xxxxx GHz` | ✅ **Marker 在主峰上**，可以拍照 |
| `Mkr1 Freq : 2.450000000 GHz` | ❌ 还在竖线上 → 按 `Marker → 右峰值` 往右跳一格再读 |

主峰预期位置（TX LO 固定 2.45 GHz）：

| 波形 | 预期 `Mkr1 Freq` |
|---|---|
| `tone-positive`（+960 kHz） | **2.45096 GHz** |
| `tone-negative`（−960 kHz） | **2.44904 GHz** |
| `tone-double-offset`（+1.92 MHz） | **2.45192 GHz** |
| `bpsk`/`qpsk`/`qam16`（+960 kHz，成形） | 约 **2.45096 GHz**，峰较宽 |

## 5. 拍照要包含的五个要素

一张合格的取证照片必须**同时看清**：

1. `Mkr1 Freq`（频率）
2. `Mkr1 Ampt`（电平）
3. `Attn`（内部衰减）
4. `Ref Level`（参考电平，用于判断是否压缩）
5. 屏幕底部 `Span` / `RBW`（换算与分辨率依据）

缺任何一项，这张图都不能用于定稿。

## 6. 读数之后的换算

- 分析仪显示的 dBm 就是**输入口上的功率**（内部衰减已折算）。
- **`-10 dB` 是板卡的 TX 数字衰减读数，不等于任何一个 dBm 值。** 真实功率只来自这台仪器的测量。
- 接头/线缆损耗未标定，所以该读数可用于**同条件相对比较**与**保守链路预算**，不能当绝对功率校准值。

## 7. 安全上限

`RF Input` 上限 **+30 dBm / 50 VDC**。本板 TX 路径有板载 PA 且原厂未给出端口上限，因此：

- 首测从**最小数字幅度 + 短时长**开始；
- 读数若进入 **+20 dBm 以上**，立刻停，加衰减器再测；
- 不要把板卡接到 `Gen Output`。
