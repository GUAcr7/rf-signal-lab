# 录像前的频谱仪对照与双 TX 方案

2026-10-28，用户希望先完整演示并录视频，提出旧板两发射口输出同样信号：一路至新板 RX，一路至 RIGOL RSA3030。用户确认频谱仪在手边，没有功分器/定向耦合器。本轮未要求改变现有射频接线，未运行发射。

## 当前功能与边界

P81 已通过电脑中转屏控三种已知信号、自然结束、实际 RUNNING 中 STOP、完整接收数据和显示验证。视频功能闭环主要还需仪器对照、当前新会话校准和一次完整录制；比赛所需工程、性能/资源对比、Skill、AI 协作等提交物仍需分别核对，不能称只缺一根仪器连接线。

当前 `embedded/arm_tx_source/arm_tx_source.c` 仅启用 DAC voltage0/voltage1，对应一路 RF 的 I/Q，不代表 TX1/TX2 两路 RF。代码要求 4 字节复样本和步长 4，其它通道先禁用。直接接 TX2 不会自动取得已验收的相同调制波形。

## 三种路线

1. **当天无需新增器件**：同一个 TX1、固定波形和配置，停止发射后分别接频谱仪/新板录制。拍摄说明为分次验证，保留设置和损耗记录；不能说两端同时接收。
2. **同一路 RF 的同时仪器对照，优先方案**：TX1 → 额定覆盖 2.45 GHz 的 50 Ω 两路功分器/定向耦合器 → 两条各自核算损耗与衰减的支路。新板 RX 保护衰减不拆除；普通 T 头不能代替合格分路器。支路损耗及分路后新背景/单音校准需要重新验证。
3. **双 TX 同波形并排展示**：需要新的独立候选程序，将同一 I/Q 同步填入两路 RF 的数据通道，检查两路物理映射、增益、端口和共享时钟/LO，验证启动/到时结束/STOP/异常释放两路均归零。保持 P81 单路回退，不能直接修改冻结 guard 或波形交付包后继续使用旧 SHA。

双 TX 可比较同样数字激励下的中心频率、谱形和合理定义的带宽，适合展示两路输出；但每路经独立 DAC/滤波/混频及板级链路，幅度、相位和杂散可能不同。TX2 的 dBm 测量不能直接充当 TX1 进入新板的功率真值。若用于定量误差表，先独立表征两路差异与两支路损耗；更直接的同源测量仍是路线 2。

## 对照项目与录像

- 先单音：同一软件设置正 IF +960 kHz，LO 2450 MHz，理想 RF 2450.96 MHz；记录两端实际读数，不把理想值当绝对校准。单音峰值和调制谱的区域中心采用各自明确指标。
- 再 BPSK/QPSK/16QAM：记录 Rs、成形参数、采样率、FFT 频点间隔，频谱仪 Center/Span/RBW/VBW/迹线模式、输入衰减、预放和带宽计算方法。比较 99% 带宽时必须定义相同积分区域/噪声处理，不能将 RBW 与 FFT 频点间隔混同。
- 功率：当前新板数字/相对功率不直接等同 dBm。对照须换算到相同参考位置，补偿实测线损/分路损耗并完成接收标定；视频可先只展示频率、谱形、带宽和相对变化。
- 三类调制在相同符号率/成形下可能有相似频谱，频谱仪谱图不单独证明 AI 类别正确，也不能未经选件/方法核验就声称测得 EVM。
- 录像包含实物接线、源屏选择/READY/RUNNING、新板动态四区/识别、仪器相应变化、STOP 后状态。若用分次测量，明确时间顺序；若用双 TX，明确仪器观察的是 TX2 同波形支路。

## 本轮适用的仪器约束及旧卡修正

使用 RF INPUT，不能接跟踪源 Gen Output。以仪器准确型号对应数据手册为准：RSA3000 系列资料的 +30 dBm 最大安全 CW 输入带有衰减≥40 dB且预放关闭条件，不是任意衰减/预放设置下都允许 +30 dBm。实际连接前依据板端输出及衰减器额定能力核算，按已验证低幅度/短时程序开始，不能用损坏极限当工作目标。

旧 `rf-spectrum-analyzer-setup.md` 的“换 TX2”不是当前 guard 的自动可用方案；中心细线也不能不经实测就一律认定为显示伪影。历史单音卡中的峰形、参考电平等示例不能泛化为所有调制和量程的判据。遵循本轮上述边界，不由历史照片替代新连接实测。
