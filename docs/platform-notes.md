## 启动状态不可靠：已第三次出现，供电是首要可疑项

2026-10-16 首次受控发射前的只读核对发现 AD9361 读回非法：PHY TX 采样率 `85727126`（正常 `30720000`）、TX0 通道采样率 `21431781`、TX 增益 `-16383.750000 dB`（合法范围 `[-89.75, 0]`），三者互相矛盾；而内核日志仍报 `AD936x Rev 0 successfully initialized`、`cf-ad9361-lpc` 也注册成功。详见 [EXP-HW-004](experiments/exp-hw-004.md)。

这与 2026-09-23 的 [EXP-HW-003](experiments/exp-hw-003.md)（TX 数字接口时序训练失败、接收设备缺失）和 2026-09-28 [EXP-P03](experiments/exp-p03.md) 第14行（首次启动 CHIP_ID 错误、重启后消失、根因未定）属于同一类问题：**上电后的 AD9361 初始化不可靠**。

用户已确认**当前使用普通 USB 线并经过 USB 集线器**供电。本页第 28 行记录的原厂要求是 **5V/1A 的 USB 供电加强线**。即"一根普通线+集线器同时承担供电与串口"，是最可能的根因，但**属待验证推断**，尚未测量输入电压/电流。

处置原则（沿用 EXP-HW-003 第49–51行）：先在明确可靠的 5V/1A 供电、直插电脑 USB 口、不经集线器的条件下做一次**有记录的冷启动**，保存完整 dmesg 与 IIO 属性；**不要靠反复重启碰运气**，连续两次同一现象即按可复现问题处理。**判断依据一律以属性读回为准，"probe 成功"不等于"配置正确"。**
