# P81 人工彩排后的恢复入口

先读 `results/p81-active.json` 和 `docs/experiments/EXP-P81-manual-screen-rehearsal-20261027.md`。P80 提速版已通过本轮实际人手三类发射、自动结束及 RUNNING 中 STOP，完整接收历史/AI/指标/显存/清理复核通过。人工按键帧至状态读回中位 APPLY 3.590 秒、START 5.350 秒、STOP 2.442 秒；最大 APPLY 6.646 秒、START 7.062 秒，不能把中位值当作每次固定等待。初次 STOP 没收到原始字节，最终明确触摸后实际 STOP 成功；前次原因未确定。

当前两板仍供电，收发已停、DDS 数字零源、全部控制连接释放。没有关机、重启或持久固件修改。TX boot `944506cc-3982-42c0-ba95-85f32ae16cb7`，RX boot `dc089a3e-9b98-48ea-97d0-a15ceb8b6389`。COM 编号必须重新识别，不能当作身份。

接法保持旧 P201 TX1 → 原衰减连接 → TLZ7xH RX1A。淘晶驰屏只经 USB-TTL 接电脑，未接旧板 J19。当前仍依赖电脑；独立直连、旧板开机恢复未验收。

若需再次演示：沿用 P80/P79 恢复流程，重新识别、确认源空闲；重启后的旧板须 prepare-source 恢复 RAM 包并重新绑定同 USB 网络身份。创建新的 RX 和新背景，发送固定 15 秒参考单音校准，再运行 `run-source-screen.cmd --rf-link-reviewed`。每次选信号后 APPLY → READY → START，RUNNING 中点 STOP 才是中途停止；默认单次 15 秒。新板仍有 15 分钟 RX 期限。不要启动并发串口/板控程序，不改冻结 P76 证书和 P79/P80 检查点。

后续优先顺序：

1. 取得并归档队友最终 HMI/TFT，保留实际烧录版本。
2. 核验旧板独立 UART 候选的启动/设备树/物理回环。当前候选尚不能视为可直接接屏；不要猜 J19 电源或地线，也不要热重载 PL。
3. 通过后再断电接屏验证双向控制，将 PC 中转控制迁移到旧板；保留原生限时/停止/清理守卫。
4. 验证旧板源包、控制服务的持久保存及断电恢复，再做真正脱离电脑的整机彩排。

P81 增量检查点依赖 P80 及其父包。当前无需重复三类算法开发或扩展独立准确率实验。
