# 模型卡：CNN-115-SYNTHETIC-v1

用途：学习/验证P201 ARM三类调制推理与量化，不作为已验收真实RF分类器。

输入1024复数点，维度[1024,2]交织I/Q float32。去复数DC、按每帧RMS归一化，零/非有限/溢出帧拒绝。Conv2→8/kernel5/stride2→ReLU→GAP510→Dense3，类别固定BPSK/QPSK/16QAM，115参数FP32。训练seed20261011、800 epoch、验证第782轮。

训练126独立母波形/1008帧，验证27/216；最终测试新seed20261012的27/216，与原数据哈希不重复。Fs1 MS/s、sps4/8、RRC0.35、SNR10/15/20dB、相位/频偏/整数偏移/AWGN；未包含真实RF、多径、AGC/ADC失真、未知调制或只噪声类别。

新测试FP32 92.5926%，INT8 MAC93.0556%，最差类别分别QPSK87.5%/86.1111%；SNR10时FP32 QPSK仅62.5%，不能声称所有条件达标。量化校准仅训练集，整数MAC+浮点重标度，完整记录及混淆矩阵见 [CNN训练记录](../experiments/exp-p09-cnn-20261011.md)。

板端FP32平均0.56309233ms、INT8 MAC1.10922671ms，均包含DC/RMS和推理、排除IO，RSS1116KiB；保留FP32候选。460字节浮点参数与180字节量化有效载荷不是整个可执行程序大小。模型SHA256 cf24285e41c9b113fd05e56498c47292884f3b792a6b097e8fe2afb0a469869b。

限制：没有真实RF准确率、置信度校准、未知信号拒识、连续接收队列、独立屏。当前板卡30.72 MS/s的未知目标帧和训练1 MS/s不同，不能直接连接并把三选一输出当已识别。需要先制定采样率/符号率/有效信号筛选和受控标签验证。原v1测试在首轮诊断中暴露，所以最终采用冻结之后的新holdout；不得以反复测试调参后的数字冒充独立测试。
