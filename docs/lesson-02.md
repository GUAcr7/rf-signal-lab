# 当前第一步：一串数字怎样表示波形

## 先理解，再运行

你已经得到 BPSK 符号序列 `[-1, +1, +1, -1]`，它告诉我们每个比特选哪一种符号。今天先补上画波形必需的一层知识：时间和采样。暂时生成一条没有承载比特信息的简单余弦波。

想象每隔同样长的时间，给一个上下摆动的物体拍一张照片，记录它当时的位置。一张照片对应一个数，把这些数按时间摆好，就能看出摆动过程。

| 名词 | 直观含义 | 本次设置 |
| --- | --- | --- |
| 幅度 | 离中间位置最远有多大 | 1；数值约在 -1 到 +1 之间，无物理电压单位 |
| 频率 | 每秒完整起伏多少次 | 1,000 Hz，即每秒 1,000 次 |
| 周期 | 完成一次起伏需要多久 | 1 ms |
| 采样率 | 每秒记录多少个数 | 16,000 次/秒 |
| 采样间隔 | 相邻两次记录隔多久 | 62.5 微秒 |

波形频率描述波形起伏，采样率描述记录速度，两者是不同的量。这里每周期有 16000÷1000=16 个点；64 个点对应 4 个周期的记录区间。后面选用其他采样率前，会再讲采样不足带来的问题。

## Python 黄金参考

黄金参考就是先用容易核对的 Python 算出正确结果，之后用它检查 FPGA 或板端程序。

模型位于 `src/rfsig/sampling.py`，三个核心动作是：

```python
sample_numbers = np.arange(num_samples, dtype=np.float64)
times_s = sample_numbers / sample_rate_hz
samples = amplitude * np.cos(2 * np.pi * frequency_hz * times_s)
```

第一行生成编号 0～63；第二行把编号换成时间；第三行算出这些时刻波形的高度。`np.cos` 用来生成规则起伏的余弦波，`2π` 表示完整转一圈。

对应公式为：`t[n] = n / Fs`，`x[n] = A cos(2π f t[n])`。

其中 n 是采样编号，Fs 是采样率，f 是波形频率，A 是幅度，t 用秒表示。

## 运行之前的理论预期

| 编号 n | 时间 | 波形数值 |
| --- | --- | --- |
| 0 | 0 ms | +1 |
| 4 | 0.25 ms | 约 0 |
| 8 | 0.50 ms | -1 |
| 12 | 0.75 ms | 约 0 |
| 16 | 1.00 ms | +1，开始下一周期 |

第 64 个点的编号是 63，所以最后一个时间是 3.9375 ms。记录区间为 `[0, 4 ms)`，不包含 4 ms 的点。浮点计算的零可能显示成非常小的数，这是计算精度的正常现象。
