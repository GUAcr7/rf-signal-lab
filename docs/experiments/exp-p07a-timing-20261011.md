# EXP-P07a：实际综合与 FIR 时序修正

日期：2026-10-11，Asia/Shanghai。状态：**修改后的独立 FIR 仿真与 100 MHz 内部综合估计通过；未布局布线、接入 ADC/DMA 或上板。**

## 发现、修改与依据

安装后的 Vivado 2021.1 首次实际综合原 FIR，目标 `xc7z020clg400-2`、63 抽头、10 ns 时钟。源码/系数/TestBench 与先前仿真资格报告的 SHA256 一致，系数 ROM 成功加载，原生退出码 0、无黑盒/常量输出。但内部 setup 裕量为 **−5.153 ns**，不通过 100 MHz 估计；hold 为 +0.252 ns。最长路径从历史样本经选择、DSP 乘加、舍入和饱和判断到输出寄存器，一拍约需 15.150 ns。

修改 `fpga/rtl/fixed_fir_iq.v`：最后一次乘加先保存完整 36 位累加结果，新增 `CONVERT` 状态在下一拍舍入/饱和。整数契约、系数、I/Q 次序和数值算法没有变化；没有降低时钟目标、截断累加器或添加 false path。修改前 RTL、TB、运行器和综合清单保存在 `results/p07-fir-timing-20261011/before-pipeline/`。

相应修改 TB 与结果检查器的周期预期。63 抽头当前在输入接受后第 **64** 拍产生 valid，最早第 **65** 拍交接输出，无暂停连续输入间隔 **66** 拍。先前的 63/64/65 拍是旧架构结果，不能继续作为当前模块的周期指标。
