## 候选定义及数据边界

`experiments/p74_phase_pool.py`与`embedded/arm_live_panel_p74/phase_pool.h`实现固定0、45、90、135、180、225、270、315度旋转，在每帧内对8次冻结INT8网络的logits取算术均值，然后仍要求三帧预测完全一致才接受。没有2/3投票、置信度补判、真实标签输入或“选择预测最正确的相位”。原P52权重、量化器、DC/RMS及FIR保持原文件不变，原P56策略不改。

这是一项推理算法变更，不能沿用原算法52/54独立测试成绩作为候选成绩。原训练本来已有随机相位/CFO增强，本轮没有声称训练时缺相位增强，也没有重训练。有限8相位群的控制结果不能证明对所有连续相位、频差、定时、未知调制都不敏感。

评估协议先保存到`results/p74-offline-20261026T094450Z/protocol.json`并核候选代码SHA，再读原验证集54帧。原训练/验证按seed分组，不随机重分；未读取原独立P52测试文件。通过验证条件后才在已暴露P73事件上做诊断回归。原验证集和P73数据都不是新的独立测试集。
