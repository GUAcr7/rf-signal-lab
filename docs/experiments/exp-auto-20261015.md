补充只读发现：原厂源已有可旁路的 8 倍 RX FIR 抽取，I0/Q0 经它送 cpack，I1/Q1 走另两通道；ADC DMA 使用 FIFO 写入而非 FFT 的 AXI Stream 握手。尚未切换其运行时 active，未改现有原始 IIO 链路。先保留原始采集，另建有缓冲和溢出计数的分析支路。

开发过程中保留的失败证据：首轮仿真 Tcl 以 '-' 开头的属性值被解析为选项，改用 -dict 后通过；直接 XSim 的两次负对照调用先后遇到批处理等号参数和 Tcl 反斜杠路径解析，使用带引号的参数与正斜杠路径后才正确触发故意数据错误。成功与失败分别保留，未把调用失败当成通过。
