日期：2026-10-24。P52 模型、量化参数、前端处理均冻结，不重新训练。

## 开始状态与目的

两板仍为上一轮启动身份，旧板 COM9、新板 COM8；新板无内核污染、接收 DMA 空闲。原 P48 开机方案保留。本轮先在独立 RAM 目录运行 AI 候选，不直接替换已通过的开机程序。

目标：消除编译时写死本次 IF 的做法；自动采背景、等待已知单音校准；无可用信号、单音、削顶或三段判别不一致时暂缓报类别；保存整个演示过程，而非只用最终截图验收。

## 固定规则（上板前确定）

- 控制请求必须包含本次 Linux boot_id、冻结模型 SHA 和新的 32 位十六进制会话令牌。没有有效请求时只显示校准待完成。
- 控制器确认发射源关闭，再让接收器保存四个完整背景 DMA 块；随后发射 15 秒已知单音。接收端独立估计两个完整块的频率，拟合误差不超过 -20 dB、差值不超过 100 Hz，且频率位于名义 960 kHz 的 ±50 kHz 内。三类共享这一个 IF。
- 背景参考是上述四块经同一冻结前端后十二帧的最大 DC 去除功率。当前三帧最小功率至少为参考的十倍，且三帧类别完全一致，才显示一个类别。这个十倍值是背景参考比，不是经过标定的 SNR。
- 削顶、已知频带内的纯单音、背景功率不足和结果不一致均不显示确定类别。它们不能证明通用未知信号检测能力。
- 原射频路径、数字峰值 256、TX 增益 -10 dB、RX 手动 0 dB 不变。每段 TX 有独立时限，不在开机时自动发射，不热加载 PL，不卸载驱动。
- 冒烟验证：85 秒同一接收上下文，三类各发射 12 秒。通过后再做 630 秒同一接收上下文；三类各四段、每段 45 秒。每段间检查源已清零并等待背景状态。
- 真值只在电脑端记录，不进入接收器。计分区间固定为提交后取得的接收时间锚点 +2 秒至 +发射时限 -3 秒，避开切换边缘。有效类别覆盖率至少 70%，已报类别的正确率至少 90%；背景与单音不应报类别。不得看过结果后下调标准。
- 记录每次显示更新，最多 4096 条，达到上限报错停止；最多 16 组同次更新的 IQ/像素/状态快照。快照只用于复核示例，整段评分使用全部历史。
- 本轮复用已暴露 seed 2026102315 波形，属于部署回归，不是新的独立识别率验证。连续 DMA 时间轴、绝对 RF 功率、通用未知拒识及物理屏幕目视均不因软件截图而得到证明。
