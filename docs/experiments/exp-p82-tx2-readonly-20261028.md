# P82 双 TX 录像方案的只读核验

本阶段只检查旧 P201 的 TX2 接口库存，未实现或启用双路发射。用户现有频谱仪，没有功分器/耦合器；现有射频连接未要求改动。本轮不校准、不发射、不改 PL 或持久启动配置。

详细路线和约束：`docs/design/video-rf-comparison-20261028.md`。

- 原实现核验：guard 仅使能一路 RF 的两个 I/Q 数据通道，步长 4，不会自动复制到第二 RF 口。
- 首次路径格式拒绝：`results/p59-p82-TX2-readonly-20261028T105600151365Z/report.json`；失败脚本版本保存在同目录。
- 固定 sysfs 只读核验通过：`results/p59-p82-TX2-readonly-20261028T105753420323Z/report.json`。四个 TX 数据扫描通道暴露且关闭，TX2 PHY 增益 -10 dB、端口 A；前后 TX 空闲、零源、boot/RF 不变。原始串口/执行脚本均留存。
- 所有控制连接已释放；新板在本阶段只接受既有状态读取，不启动新会话。不能凭此报告宣称双路输出或视频对照完成。

当前决策边界：可不增加器件先用同一 TX1 分次录制；若需同时同源定量对照，优先增加合格功分器；若采用用户提出的 TX1/TX2 并排展示，需要独立双通道候选与守卫/停止实测，并如实标明两个模拟输出的差异。P81 单路版本保持不变。
