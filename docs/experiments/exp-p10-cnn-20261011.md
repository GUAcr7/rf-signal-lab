# P10：训练后的 CNN 在 P201 ARM 上的 FP32 / INT8 对照

日期：2026-10-11。输入为保存的合成float32 I/Q；C程序实际在Cortex-A9运行，包含去直流和RMS归一化。使用GCC8.3 hard-float，禁用fast-math/FMA合并；没有发射、修改固件或安装板端神经网络框架。

## 量化和来源

校准仅使用v1训练集1008帧。input/activation采用训练值绝对值/激活99.9百分位尺度，卷积和稠密权重采用各层绝对最大值尺度；四个尺度分别0.013564633205533028、0.06080599129199982、0.22620536386966705、0.059977076947689056，完整保存在calibration.json。round-nearest ties-to-even；输入/权重/激活INT8，卷积偏置及两层MAC累加INT32；保留FP64去直流/RMS、激活重标度和最终logit反量化，稠密偏置为FP32。**这是混合计算的INT8 MAC实现，不能称作完全整数推理。**

115个FP32参数有效载荷460字节；量化有效载荷180字节（104字节INT8权重、32字节卷积偏置、12字节稠密偏置、32字节尺度），均不含NPZ容器和C程序。为公平运行两种模式，当前二进制同时包含两套权重，其整体大小不能用这两个载荷数替代。

## 实测结果

216个新独立合成测试帧，来自27条母波形。两种ARM类别全部与各自冻结的Python参考一致。FP32最大logit绝对误差1.3947486877441406e-5，预定容差abs5e-4/rel1e-4；INT8 logit误差0，预定abs1e-10。FP32准确率92.5926%，量化93.0556%，完整逐类与SNR结果见准备报告；0.46个百分点差异只描述本小样本，不能推断量化提高了泛化能力。

5次预热、100次测量，计入去直流/RMS和前向，不计文件IO/串口/采集/界面；交替微扰一个输入防止固定数据优化。当前INT8因为标量重标度和实现代价较慢，**候选默认保留FP32**，不宣称量化加速。可支持的分类更新率须和采集、选帧、队列、输出一起测量，不能依据单次延迟宣称持续30.72 MS/s。
