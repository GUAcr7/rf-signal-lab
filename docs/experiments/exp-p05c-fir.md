## 1. 目的与实验前指标

复用 P04 已核验的三份完整仿真 I/Q，不重新生成或改写源文件。Fs=1 MS/s、Rs=125 ksym/s、RRC 滚降 0.35，理想频谱支持为 ±84.375 kHz，有限截断仍有带外残留。

先规定通带 |f|≤100 kHz，最大绝对幅度增益偏差≤0.1 dB、峰峰纹波≤0.1 dB；阻带 200 kHz≤|f|≤500 kHz，衰减≥50 dB。初选 63 抽头对称 Hamming 窗 sinc，设计截止 150 kHz、直流增益 1。150 kHz 约为半幅度点，不是要求保持幅度的通带边缘。

理论因果 FIR 为 `y[n]=sum(h[k]*x[n-k])`。实系数对称，群延迟为 31 个样本，即 31 µs；输入 N 点时全输出 N+62 点。离线比较仅对齐这 31 点延迟，不拟合增益/相位，也不再次归一化。三类延迟对齐样本 NRMSE 各要求≤1%，不称为符号 EVM、误码率或 AI 准确率。

这是额外低通是否能保留目标波形的候选参考，不代表最终必须添加相同 PL FIR。真实目标的频偏、采样率、目标频带及 AD9361 已有滤波仍需决定最终设计，尤其不能把这套系数直接用于当前 30.72 MS/s 的板卡输入。

## 2. 本轮实现

| 文件 | 内容与边界 |
| --- | --- |
| `src/rfsig/fir.py` | `design_lowpass_fir` 生成实系数；`apply_fir_full` 保留完整因果输出；`FirStream` 保存连续块历史并显式冲出尾巴 |
| `tests/test_fir.py` | 手算、显式求和、解析单音、频响/延迟、状态和格式边界测试 |
| `experiments/p05c_fir_reference.py` | 固定指标、读取旧 P04、数值对照、图、计时与保存回读；仅使用 NumPy/Matplotlib，不导入 IIO 或访问板卡 |
| `docs/lesson-p05c-fir.md` | 指标依据、滤波含义、延迟/边界与如何读本次结果 |

分块输入每次产生等长因果输出，`finish` 补零冲出 M-1 点尾巴并关闭；重复结束或结束后推进报错，`reset` 开始新记录。空块不推进状态，输入错误/溢出不改变已有历史；系数与历史均保留独立副本。

当前 IIO 监测各块的连续性未知，本轮没有把快照拼接进这个有状态滤波器，也没有改动现有监测窗口。

## 3. 理论和独立测试

新增测试使用手算非对称复数卷积、逐点定义求和、标量 sinc/Hamming 公式、DC 稳态与冲激、解析正负单音响应，避免单靠同一个卷积函数自证。分块覆盖单点、小于历史长度和不规则切分；末尾输出必须完整保留。

发现并修正两个边界：NumPy 复数采样率/截止频率不能经 float 转换静默丢弃虚部；极小 cutoff/Fs 时，把 DC 归一化中本来会约掉的公共比例因子去掉，避免系数整体下溢为零。正常设计的定义不变。

专项测试 **64 passed in 0.52s**；最终代码的全工程回归 **367 passed in 1.22s**，见[实际回归日志](../../results/p05c-fir-regression-20261009t014534845182z.log)。这次确实运行了代码回归，不沿用以前的 303 项数字。

## 5. 目标平台、上板与性能边界

本轮按照“原理 → 浮点参考 → 理论与指标 → 单元测试 → 电脑参考实现 → 独立对照 → 离线实测 → 记录”推进。目标 FPGA/ARM 实现、定点模型、TestBench、上板与性能均待 P06/P07 条件满足后进行；本轮无 RTL，所以不为形式补空 TestBench。没有模型训练，数据集划分/AI 准确率/量化指标本步不适用。

电脑性能：QPSK 16457 点、63 抽头，1 次暖机后计时 20 次，完整 `apply_fir_full` 调用中位数 **0.37105 ms**，包含输入校验和数组分配。它不含读取文件、绘图、分块调度、传输、板卡、FPGA 或 AI；不是硬件吞吐率或端到端响应保证。

本轮未安装依赖、未启动 GUI、未访问板卡或改动射频配置、未发射/烧录，未改变 Git 暂存区。results 仍被 Git 忽略，备份工程时须包含实验产物。
