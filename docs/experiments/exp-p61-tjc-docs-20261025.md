日期：2026-10-25。来源：用户提供T1系列4.3英寸480×272商品截图、官方开发资料、串口下载/SD下载和视频链接。完整实物型号仍未提供，本轮已通过文字询问背面型号。

## 实际完成

读取官方资料并归档21个成功页面、1个失败的推测路径。网页读取工具对wiki HTTPS请求出现502/超时；Python标准库读取用户给出的HTTP地址成功。原始失败没有被写成成功，也没有因此改用经销商参数替代实际型号规格。推测的`code/index.html`不存在，随后从官方导航找到并读取`grammar/index.html`。

原始资料报告：

- `results/p61-tjc-docs-20261025T034055Z/report.json`：用户4个链接及官方T1产品/结构页。
- `results/p61-tjc-docs-20261025T034128Z/report.json`：指令/返回目录、编辑器、规格与选型入口。
- `results/p61-tjc-docs-20261025T034151Z/report.json`：T1目录、printh、get、按钮/数值返回。
- `results/p61-tjc-docs-20261025T034212Z/report.json`：两种候选型号页面及失败的推测路径。
- `results/p61-tjc-docs-20261025T034315Z/report.json`：实际语法目录。

每个成功页面有原HTML字节、文本、URL和SHA；获取工具为`experiments/p61_fetch_tjc_docs.py`。商品截图副本位于`results/p61-tjc-integration-20261025T034600Z/user-product-page.jpg`，它是商品页，不是实物背面标签。

新增[旧板信号源屏接入准备](../design/tjc-source-screen-20261025.md)，明确T1裸屏3.3V与带板模块5V供电区别；候选型号未视作已选定实物，供电和UART电平分别核对。将早期“串口屏显示接收结果”队员任务书标为历史，当前屏幕用途为旧板发送控制。

新增无IO协议子集`src/rfsig/tjc_protocol.py`及17项测试。`results/p61-tjc-protocol-tests-20261025.xml`全部通过；处理官方按钮/get示例、数值小端和载荷含结束符、拆包/粘包、缓冲上限、畸形帧及注入拒绝。没有打开串口或绑定按键到RF，也没有编译HMI/TFT文件。

## 本轮结论与限制

资料足以继续准备软件协议和发送端页面；尚不足以批准实物接线、供电或选定下载型号。完整型号、实际针序/电平、旧板UART固件部署及回环仍待完成。当前协议子集通过只说明离线字节处理符合所核对范围，不证明实际屏幕兼容或物理通信通过。

本轮未操作板卡、串口、射频、磁盘/SD卡或软件界面，不改变P59硬件验收结论。最后硬件状态仍须从P59交接读取并在下一次操作前复查。汇总、校验和本轮增量归档见`results/p61-tjc-integration-20261025T034600Z/report.json`；不是新的全项目硬件检查点。
