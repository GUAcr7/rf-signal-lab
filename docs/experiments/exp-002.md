## 1. 原理讲解

先学习 lesson-02：固定时间间隔记录波形的数值，形成采样序列。

## 2. Python 黄金参考

`rfsig.sampling.sample_cosine` 返回一维 float64 时间与幅度数组；时间单位秒。
本次参数：f=1000 Hz、Fs=16000 samples/s、N=64、A=1、初始相位为零。

## 3. 理论预期

每周期 16 点，间隔 62.5 μs；n=0/4/8/12/16 对应 +1/0/-1/0/+1；四周期记录区间 [0,4 ms)，最后一点 3.9375 ms。

## 4. 单元测试

检查时间间隔/端点、手算四分之一周期值、16 点重复性，以及 A=2 时完整周期平均值为 0、均方值为 2；另检查无效参数。
幅度绝对误差容限 1e-12，时间间隔绝对误差容限 1e-15 秒，覆盖本实验短序列 float64 舍入误差，不代表未来定点硬件容限。

运行命令：`.\.venv\Scripts\python.exe -m pytest`；`.\.venv\Scripts\python.exe experiments\level0_sampling.py`。
运行结果：2026-09-21 全部 23 项测试通过（原有 7 项 BPSK 测试、用户保留的副本 7 项、新增采样测试 9 项）；不是 23 个不同功能。采样间隔 62.5 μs、每周期 16 点、最后一点 3.9375 ms、五个关键值均符合预期。实验程序成功保存波形图，已目视核对四周期、坐标单位与采样点标记。团队成员尚待自行复现。
