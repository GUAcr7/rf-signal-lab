## 步骤与预设验收口径

1. `experiments/p68_rf_dashboard_trial.py`持有固定入口互斥锁；两板身份、内核、参数、原启动文件逐项核对。
2. 在新板独立tmpfs目录运行P67，最长300秒；以本boot、冻结模型SHA和随机新令牌采4个背景块，进入WAIT_PILOT。
3. 发送15秒单音，等待共享IF校准；再依次发送三类调制信号。请求6组同源I/Q、显存、AI JSON快照（校准前背景、单音、三类调制、结束后背景）。
4. 所有发射结束后继续接收背景至300秒，验证显示仍更新、无源时拒判，最后正常释放RX资源。五分钟接收不等于五分钟连续发送或持续分类。
5. `experiments/p68_evidence.py`打包并下载RAM证据，逐块SHA、完整压缩/解压SHA及gzip CRC核验，限定8MiB压缩/16MiB解压，不把成功传输解释为ADC无丢样。
6. `experiments/p68_review_rf.py`使用完整原始AI历史评分，沿用既有稳定窗口：首个发送后观察+2秒至末尾前3秒；分类覆盖率至少70%，已分类正确率至少90%。单音与背景不得输出已接受类别。
7. 对每个快照，独立Python冻结前端/量化CNN及功率/拒判策略重算；实际AI页脚按字形像素核对。相同I/Q通过宿主C重绘，I/Q区域要求像素完全相同，频谱区域容许1%以内的ARM/宿主FFT取整差异。
