## 本步原理与范围

旧窗口在已经保存的文件中逐帧取数；新模块每次通过 IIO 从实际 P201 读取一块新的 RX 返回数据。每块 1024 点，在当前 30.72 MS/s 下只代表约 33.33 µs 的块内采样。块与块之间的时间连续性、ADC 丢样和数据抵达延迟没有硬件时间戳/计数证据，均写为未验证。

不拼接不同 RX 块来假造连续样本，不把块号乘 1024/Fs 当作连续时间。每块保存实际主机 I/O 起止计时及增益快照；瀑布图纵轴用接收块编号。 observed_blocks_per_host_second 是该短实验中的取块速率，不能当作 ADC 吞吐或实际 GUI 帧率。

## 实现与配置

- `src/rfsig/rx_monitor.py`：有限会话、独立逐块分析、固定首个正功率参考、保存、P201 RX 接口及停止/错误清理。
- `experiments/p05_rx_monitor_check.py`：三个短会话及保存重算，不启动 GUI。
- `host/rx_monitor_viewer.py`、`run-analyzer-live.cmd`：用户启动的新监测窗口。工作线程收数，界面线程绘图；容量 1 的显示队列可替换旧快照，会话仍保留全部有限接收块。
- 复用既有频谱、功率与 99% 区间参考，不新增 DSP 算法、RTL 或 AI 模型。

读回并沿用：P201、Fs=30.72 MS/s、RX LO=2.4 GHz、RF BW=18 MHz、slow_attack；增益读数在本次三会话中均为 71 dB。读取 BIST/PRBS/loopback 均关闭、DDS scales 为零，接收格式为小端 signed 12/16、shift=0。没有调谐、发射、开启 BIST、安装或烧录。每块前后核对采样率/LO/带宽/增益模式/端口；manual 模式还检查固定增益，AGC 模式只记录增益快照。

数字相对功率使用本会话首个正功率块作为固定参考；首块为零则保持 N/A，直到有正功率参考。即使参考固定，AGC/未知输入下也不能把数字比例直接当作射频输入功率变化。每次重新 Start 新建参考，不能默认跨会话比较 dB。
