# P69：中心频率与99%区域带宽接入实体LCD

日期：2026-10-26。承接P68的限定单源ROI诊断；不是任意无线信号的通用检测或绝对射频标定。

## 实现

新增`embedded/arm_live_panel_p69/roi_math.h`和`measurements.h`。保留P67的I/Q、频谱、瀑布图及P56冻结模型，在右下显示：LO读回值加区间中点、99%区域带宽、中心偏移、区域数字功率和相对背景变化。

ROI为本次共享单音校准IF±600kHz；积分1024点、8帧Hann能量归一化谱，对bin重叠区间作等尾0.5%/99.5%积分。未减噪声，99%范围仅针对指定区域。四个校准背景块的32帧FFT形成当前令牌的固定参考；功率至少高出背景10倍才允许测量。主峰在ROI外、谱触及区域边缘、未校准、无信号、削顶或停止均不输出有效数值。测量有效性不冒充AI置信度。

`LO+center`是接收LO设置值与测得偏移的和；FFT间隔30kHz、bin内插值不是Hz级绝对频率精度。数字功率/相对背景不是dBm或严格测量SNR。原背景块未逐个归档，实际参考数值和令牌绑定在测量记录中。

测量JSON/历史、AI/原始I/Q/显存均绑定同一source block。新增每次快照的`shot-*.metrics.json`；快照请求变化时，先核对已经保存的AI块号再附加指标，避免两个请求竞争导致错配。停止后当前数值清空，保留的波形明确显示RX STOPPED。

## 失败与修正

1. 首个测试夹具把两个C语句写同一行，被严格告警拒绝，错误输出又触发Windows/WSL编码解码问题。拆行并保留容错日志解码后15项通过，未降低编译告警。
2. 结束清理失败时明确清除clean_stop，避免SIGTERM路径掩盖测量归档错误；重新构建并完成12场景回归。
3. RF试验生成器首次按Windows默认GBK读含中文的既有源文件失败；改为显式UTF-8。失败发生在开串口前，无板端操作。
