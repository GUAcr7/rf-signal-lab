# P08：合成数据集 v1 局部验收

日期：2026-10-11。数据来源全部为数学合成，未使用真实 RF 未知样本作为三类训练标签。

## 数据构成

BPSK/QPSK/16QAM 三类、名义 SNR 10/15/20 dB，每类每个 SNR 20 条独立母波形，共180条。每条8192个复数采样点，切成8个1024点非重叠帧，共1440帧；每类480帧。Fs=1 MS/s，sps=4/8，RRC滚降0.35、跨度10符号。

三个调制类别使用完全相同的信道条件安排和分布：幅度0.6～1.4、随机相位、频偏±0.03倍符号率、整数采样偏移及复数AWGN；符号/噪声随机种子按类别独立。没有多径、真实ADC、AGC或硬件失真。源比特、干净波形、加噪波形、每帧及文件哈希均留存。

先按独立母波形索引划分再切帧：train 0～13、validation14～16、test17～19，得到126/27/27条母波形、1008/216/216帧。检查母波形、源比特、帧身份和哈希，无跨集合重复。相邻帧有统计相关性，216测试帧不是216次独立采集。

SNR定义为保存后干净复数平均功率与所加复数噪声平均功率之比；实际整条记录测得9.9229686～20.0764518 dB。这是仿真SNR，不能视作板卡的射频SNR。
