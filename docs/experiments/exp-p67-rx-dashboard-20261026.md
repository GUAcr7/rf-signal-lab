# P67：新板四区接收总览（2026-10-26）

## 目标与范围

用户把旧板淘晶驰串口屏交给队友，要求在两板连接通电后继续推进。选择W3：新TLZ7xH的I/Q、频谱、瀑布图与数字指标总览。旧板串口屏HMI、PL及P57持久启动保持原状；P67先作可回退的RAM试验。

## 实现与测量定义

- `embedded/arm_live_panel_p67/dashboard.h`：800×480四区总览，左上64点I/Q、右上1024点FFT频谱、左下最多96行瀑布图、右下数字功率/统计/采样参数，底部保留P56 AI状态。
- 每次绘图与AI取自同一个65536样本DMA块；绘图分析前8192样本（8个1024点Hann FFT），AI沿用完整块的冻结前端/模型。64点时域图横向跨度63/Fs，不混称完整采集时长。
- 频谱单位为经Hann能量归一化的`counts²/bin`，非dBm和功率/Hz。频谱与瀑布图固定使用−20至70dB显示范围，不逐行按峰值归一化；瀑布图每列显示所覆盖频率bin的最大值。
- 瀑布图纵向是实际显示过的快照，顶部旧、底部新，最多96行。DMA块可能被UI跳过，ADC缺口未知；无连续ADC时间轴或无丢样声明。
- 平均功率为前8192点的`mean(I²+Q²)`。相对功率以本进程首个非零显示记录为参考，包含未知输入和噪声，非信号专属功率。
- `record 99% width/midpoint`是整条记录频谱的等尾0.5%至99.5%区间及其中点。bin内采用均匀密度插值；分辨率仍为Fs/N=30kHz。它不是已检出信号的中心频率或占用带宽，界面及JSON明确标注`not target OBW`/`target_bandwidth_validated=false`。零输入显示不可用，禁止把宽带噪声统计冒称目标带宽。
- 原P56校准、拒判与模型完全复用；无本次有效校准不显示分类。

## 实板步骤与验收

试验脚本`experiments/p67_board_trial.py`独占现有控制锁，重新读取身份、RF配置、内核和原持久文件哈希。新程序上传独立tmpfs目录并核SHA，不覆盖P56/P57。限定接收120秒，I/Q、频谱、瀑布图和AI状态实时更新；最后自动cancel/join/release，检查scan及DMA归零。保存原始I/Q、显存、AI完整历史及全部状态，经逐块/完整SHA及gzip CRC归档。

实测与后续复核权威入口：

- `results/p59-p67-dashboard-trial-20261026T021044611428Z/report.json`
- `results/p67-active.json`指向最终复核与本轮检查点。

最终复核：`results/p67-board-review-20261026T021543Z/report.json`通过。实际运行120.008391秒、232次显示更新，最后source block=56079，233条AI历史（232条需要校准及最后1条STOPPED），最大RSS=3636KiB。收发均已停止，串口关闭，两板仍通电，没有正常关机或断电操作。

复核使用归档的原始65536点I/Q，前8192点的平均数字功率与NumPy误差为0；记录99%区间宽度差0.779Hz、中点差0.366Hz（数值实现一致性，不代表RF精度优于30kHz分辨率）。宿主C重绘的I/Q及频谱区域与板端显存逐像素均相同。原持久启动文件和AI模型哈希不变。

用户确认“能看到四区，但只看到停止画面”。因此实体屏四区可见已确认，运行时动态更新尚无人眼确认；不将日志中的232次软件更新改写成人眼确认。试验到时显示RX STOPPED、AI STOPPED是正确终态。
