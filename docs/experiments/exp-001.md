## 1. 原理讲解

BPSK 用两个相差 180° 的相位状态表示两个二进制值。本项目约定 0 对应符号系数 +1，1 对应 -1。本实验只处理符号系数，不生成载波波形。

## 2. Python 黄金参考模型

- 入口：`rfsig.map_bpsk`
- 输入：一维、非空、仅含 0/1 的序列
- 输出：同长度 `float64` NumPy 数组
- 随机种子：不使用随机数

## 3. 理论预期结果

输入 `[1, 0, 0, 1]`，逐项查映射表，预期 `[-1.0, 1.0, 1.0, -1.0]`。预期值在运行函数前由映射约定得到。
