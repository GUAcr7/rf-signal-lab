日期：2026-10-10，Asia/Shanghai。本文件保留首次定点/RTL 仿真记录。当前状态（2026-10-11）：**实际综合发现 100 MHz 估计失败，增加一次转换寄存周期后，18 组重新仿真及内部综合估计通过；仍未实现、接入原厂工程或上板。** 当前周期、来源和报告见 [综合与时序修正](exp-p07a-timing-20261011.md)，下文旧周期数仅用于历史复核。P07 整阶段未完成。

## 目的与知识点

浮点数适合先验证算法；FPGA 的寄存器有固定宽度，必须先明确每个整数代表什么，以及舍入和超出范围时怎么处理。本实验把已经通过的 P05c FIR 转成可复核的整数契约，然后让 Python 和电路仿真处理完全相同的输入。`valid/ready` 表示一笔数据只有在两个信号同时为 1 的时钟沿才交接；下游暂时不能接收时，输出必须保持。

本次授权为自主完成项目文件、程序与验证，保留实验记录。没有访问当前板卡、改 RF 配置或烧写固件。原厂工程的采集接口保持独立。

## 固定契约与理论预期

| 项目 | 契约 |
| --- | --- |
| 输入 | 每对 I/Q 为两个有符号 12 位原始整数，范围 -2048～2047 |
| 系数 | 63 抽头、有符号 18 位、17 位小数；整数除以 131072 得到实际系数 |
| 累加 | 有符号 36 位；精确累加，不绕回 |
| 输出 | 除以 131072 后就近舍入，恰好半整数时取偶数；有符号 16 位饱和，I/Q 分别给标志 |
| 状态 | 零初始历史；连续分块保留历史；完整结束补 M-1 个零，输出 N+M-1 对 |
| 波形尺度 | P04 仿真波形统一乘 1024 计数/单位；不按每条记录重新归一化 |
| 适用采样率 | 1 MS/s 离线候选；不抽取，不可直接套到当前 30.72 MS/s 接收 |

理论上零输入应产生零输出；脉冲应揭示系数顺序，低频单音应通过、高频单音应被压低。所有合法 63 抽头输入的保守累加绝对值上界为 16,911,433,728，小于有符号 36 位的正上限 34,359,738,367。滤波群延迟为 31 个样本，在本实验 1 MS/s 下为 31 微秒。

## 可移植 C99 参考：电脑执行通过

新增模块位于 [embedded/fir_reference](../../embedded/fir_reference/)，接口 `fixed_fir.h`、实现 `fixed_fir.c`、文件检查驱动 `fir_hex_cli.c`；复现入口 [p07_fir_c_check.py](../../experiments/p07_fir_c_check.py)。模块使用调用者提供的固定状态，不在每个样本处理时分配堆内存；系数首项乘当前输入，显式 reset 保留系数并清除历史，finish 输出完整零尾巴并关闭当前流。使用先检查范围的 int64 精确累加，以及无符号幅值除法/余数进行偶数舍入，避免有符号右移和越界取反。

正式报告：[p07-c-reference-20261010T125054720966Z/report.json](../../results/p07-c-reference-20261010t125054720966z/report.json)。实际 Windows 宿主 GCC14.1.0、`x86_64-w64-mingw32` 严格编译零诊断；先核验 126 个保存的向量文件，再对照 18 组完整输出：I/Q、双饱和标志及双精确累加器全部一致，**72,356 个复数输出通过**。显式 reset 后再运行全部向量仍一致，共 **144,712 个输出**；21 个直接舍入边界、10 个坏文件/长度拒绝、3 个越界累加器拒绝检查通过。

此项是未来目标实现的可移植准备，**没有生成 ARM ELF、上传板卡或证明 ARM 速度**；不可将电脑 GCC 的成功当作 ARM 兼容性通过。测试保持原有量化契约，不擅自接入实时监测或替换 PL 算法。

## 性能与硬件边界

当前为每个时钟处理一个抽头的串行 MAC 结构；63 抽头无暂停时每 65 拍接收一对 I/Q。在仿真 10 ns 时钟下，结构计算上限约 1.538 MS/s，属于根据周期数计算的预期，**不是器件实际达成时钟或实测吞吐**。不能直接承接 30.72 MS/s ADC，后续必须先确定抽取/缓存或并行结构，并记录丢弃规则。

LUT/FF/BRAM/DSP、实际时序裕量、板端延迟与吞吐全部**待验证**。时钟约束、原厂 PL 接入、DMA/ARM 软件、FFT/加窗/功率谱模块也仍待做。没有为了形式生成 TestBench 以外的假上板结果。
