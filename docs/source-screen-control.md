# 发送端串口屏使用与恢复

当前接法是淘晶驰屏通过 USB-TTL 接电脑，电脑通过旧 P201 同一根 USB 上的网络控制发射，新 TLZ7xH 保持现有接收显示。屏幕尚未直连 J19，控制服务尚未固化到旧板。电脑需保持运行，关闭程序后屏幕显示 OFFLINE。

## 已对齐的屏幕工程

实物为 TJC4827T143_011C，序列号 D1273501630AD655，115200、8N1、page0。按钮 ID 1 至 4 选择 TONE/BPSK/QPSK/16QAM，5 应用，6 开始，7 停止，8/9 时长减/加。只处理弹起事件。文字控件是 t1 状态、t2 选择、t4 秒数，使用短文字，不再采用旧计划中的 vaTag/nDur/tState 名称或长 APPLIED 后缀。

保留队友原 HMI/TFT 是后续恢复屏幕工程所需的准备；本机目前只有两份 Word 交接文件和已烧录的屏，没有收到 HMI/TFT 文件，本轮没有重刷屏幕。

## 人工操作

先由固定恢复流程完成认板、波形 SHA 检查、新接收会话及新背景/15 秒参考单音校准，再打开 `run-source-screen.cmd --rf-link-reviewed`。这个参数只用于原同轴与原衰减保持不变的接法。启动界面本身不发射，且必须逐次应用、开始。

1. 选择 BPSK、QPSK 或 16QAM，显示 SEL 加当前信号。
2. 点 APPLY，出现 CHECKING，等 READY；不要在 CHECKING 时连续点开始。
3. 点 START，先显示 STARTING；只有原生发射回执到达才显示 RUNNING。
4. 按屏幕秒数到时结束，或在 RUNNING 时点 STOP；确认清理后才回 IDLE。
5. 每次结束后重新 APPLY 才能再次 START。修改选择或时长会使旧应用失效，发射中修改会请求停止当前任务。

第一版只使用已验收的固定 RF 档位，时长 8 至 60 秒，默认 15 秒。它没有新增频率、采样率、增益、调制符号率或任意波形输入功能。TONE 用于新接收会话的 WAIT_PILOT 校准阶段，不能把旧校准直接跨会话使用。

## 下次由 AI 执行的恢复顺序

1. 读 START-HERE 与 P79 恢复记录，重新核对 USB 设备和两板 boot，不套用 COM 编号。新板的 P76 持久接收版本保持不变。
2. 先确认 TX 空闲及数字零源；旧板每次重启后使用固定 prepare-source 恢复 RAM 波形，并逐项核 SHA。
3. 运行 `experiments/p79_bind_usb_network.py`，要求串口与网络是同一 P201 型号、同一 boot，绑定 SSH 公钥；身份不符时拒绝发射，不静默切换。
4. 按 `experiments/p79_prepare_screen_session.py` 创建新 RX 并采新背景；用已核验的网络 guard 发送 15 秒参考单音，例如 `experiments/p79_cancel_guard_trial.py --natural --seconds 15`。确认 ready、原生清理及源空闲后再开启人工屏控。
5. 使用上面的人工入口。新板每次 RX 最多运行 15 分钟；到时 RX STOPPED 正常，需要新会话时重新走背景与单音流程。

不要并发启动 SecureCRT、旧实验或第二个控制程序。入口使用板卡互斥锁。屏幕失联、错误回包或任务故障会请求停止并锁定当前任务，不能通过重新点开始绕过。

## 验收边界

人工九键与回显、人工部分真实发射，以及协议自动回归是不同证据。`--protocol-regression` 是明确的实验开关：通过实屏 printh 回放已验证的按键协议帧，经过相同串口解析、控制状态机和真实 RF 链路；它不等同真实手指触摸或屏幕 click 事件。本 HMI 的 click 指令没有自动回传勾选的键值，因此不能据此声称完成全人工彩排。

P81 已补齐电脑中转模式的完整人工三类发射及 RUNNING 中 STOP 彩排，原始按键、原生停止/清理和完整接收历史复核通过，详见 P81 实验记录。后续仍需旧板独立 UART 物理回环和屏控服务下沉、旧板持久化恢复，以及脱离电脑的整机彩排。接收算法独立成绩、ADC 连续无丢样、绝对功率和 RF 频率标定均不因本轮屏控联调而改变。

## P80 按钮提速更新

人工入口现默认使用 --fast-control。收到按键帧后，本次协议回归的 APPLY/START/STOP 目标状态等待分别约 3.5/5.3/2.6 秒，原来约 9.8/18.5/6.4 秒。首次连接先完成完整检查和 RAM helper 部署，进入 IDLE 后再操作。检查没有取消；去掉该参数可显式回退原版。详细记录和恢复方法见 P80 实验及恢复清单。
