# 第一课：通信信号、数字调制与 BPSK

本课结束时，你应能说明：0/1 是要传递的信息；波形是携带信息的物理形式；BPSK 用两种相差半圈的波形状态表示 0/1。

## 1. 什么是通信信号

假设一块板要向另一块板发送 `0 1 1 0`。这串比特是信息，现实线路和空间中传播的则是随时间变化的电压、电流或电磁场。约定如何从这些变化中读回信息，就能通信。

因此，“通信信号”可以先理解成：按照约定携带信息的、随时间变化的物理量。在 Python 中，我们先用数字数组表示它在一系列时刻的数值；如何选这些时刻在下一课学习。

## 2. 什么是数字调制

无线发送常用一条规则振荡的波作为载波。可以把载波看成运输信息的基础波形，再用比特控制它的某种属性。

用余弦波表示载波：

`c(t) = A cos(2π f_c t + φ)`

- `t`：时间，单位秒。
- `A`：振幅，决定波形上下摆动有多大。
- `f_c`：载波频率，表示每秒振荡多少次，单位 Hz。
- `φ`：相位，表示相对于统一参考，这个振荡处于一圈中的什么位置。

例如两个人转动方向和速度相同，但一个指向上方时另一个指向下方，就相差半圈，也就是 180° 或 π 弧度。

数字调制就是：按数字信息，从约定的波形状态中选择要发送的状态。“数字”指信息是离散的，不代表发出的波形必须是方波，也不代表波形只允许取 0 和 1。

## 3. 什么是 BPSK

BPSK 是 Binary Phase Shift Keying，中文为二进制相移键控。

- Binary：选择两种状态。
- Phase：被选择的区别是相位。
- Shift Keying：按输入信息切换到相应状态。

本项目先约定：

| 比特 | 符号系数 | 相对于参考载波的相位 | 该比特时间段内的信号 |
| --- | --- | --- | --- |
| 0 | +1 | 0° | `+A cos(2π f_c t)` |
| 1 | -1 | 180° | `-A cos(2π f_c t)` |

这里的“符号”是一次选择并发送的状态。BPSK 只有两种状态，所以一个符号承载一个比特。这个结论不能直接套到其他调制方式上。

映射约定可以整体反过来；关键是发送端、接收端和测试使用同一约定。

为什么负号表示相差 180°？因为 `cos(θ + π) = -cos(θ)`。把余弦波整体上下翻转，等效于将它的相位移动半圈。此时振幅大小和载波频率没有改变。

所以对序列：

```text
比特：      0    1    1    0
符号系数： +1   -1   -1   +1
载波状态： 正向  反向  反向  正向
```

“0”不是关闭信号；“1”也不是频率加倍。连续两个 1 保持同样的相位状态，不是在每次遇到 1 时额外翻转。后者属于另一种编码约定，不是我们这里的普通 BPSK 映射。

上述分段是最简单的理想教学模型。实际系统如何让符号之间更平滑、接收端如何找到参考相位，留到对应课程再解释。
