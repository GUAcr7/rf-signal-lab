## 从零复现

Python 3.10+，安装Icarus Verilog（同时包含iverilog和vvp）。执行：

    python validate.py --tool-root <Icarus安装根目录> --output <新的短输出目录>

validate.py会复制Skill后运行正反案例，输出目录必须不存在。单个案例命令见Skill的README.md。不要求安装NumPy、Vivado或接板卡；第三方工具不随包分发。本轮本机为Windows/Python3.12/Icarus13，尚未在另一操作系统或另一块板上执行。
