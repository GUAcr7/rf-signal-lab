# 真实射频学习与离线演示包

本包使用旧P201发射、新Tronlong板接收的已保存真实数据。无需连接板卡、屏幕或网络即可回放；标签来自已知发送配置，不是AI识别结果。首次在新电脑安装Python依赖时需要下载，依赖装好后离线运行。

## 直接开始

1. **先完整解压ZIP，不能在ZIP内部运行。** 当前项目电脑：双击 `run-demo.cmd` 即可。另一台电脑需要先有Python（本包在Python 3.12验证）；第一次双击 `setup.cmd` 安装依赖，之后只用 `run-demo.cmd`。
2. 选择“BPSK / QPSK / 16QAM / TONE”，选择采集块1–4，点“开始/暂停”。每块共64个分析帧，播放完自动停止，点“重新播放”从头开始。
3. “显示全频段”切换完整观测频段与局部放大；“保存当前画面”在 `exports/` 生成PNG、当前帧/瀑布图NPZ和JSON参数记录。不会覆盖原始数据。
4. 直接运行 `python example_read.py` 查看读取示例。若有多个Python，使用 `.venv\Scripts\python.exe example_read.py`。仅需要NumPy即可读取NPZ；演示界面还需要Matplotlib及Tk图形支持。

## 文件与数组

- `cases/*.npz`：`iq_counts` 是 `[4, 65536, 2]` 的有符号int16，最后一维依次为I、Q；`iq` 是 `[4, 65536]` 的complex64，严格等于 `I + 1j*Q`，没有归一化或滤波；`sample_rate_hz` 是30720000。
- `cases/*.json`：采集参数、已知标签、启动身份、源文件SHA和逐块质量记录。`index.csv` 用Excel或文本编辑器查看，每行对应一个原始DMA块。
- `originals/*.bin`：对应的原始打包RX1 I/Q，格式 `le:S12/16>>0`。16位存储字高4位未定义，不能直接按普通int16读取；解码必须只取低12位再符号扩展。
- `evidence/`：本轮原始采集、回传和质量报告副本。报告里的绝对路径仅用于追溯原项目；回放程序只使用包内相对路径。
- `manifest.json`：每个静态文件的字节数与SHA256。程序启动时先校验；文件损坏或数据与原始码值不符就停止。
- `previews/`：四种信号的离线预览图；它们不是小屏实体照片。

from pathlib import Path

## 本包的适用范围

每种信号只有一次限时发射会话，4个DMA块共享同一个131072点循环发送波形；三种调制的随机种子都是20261016。**用于学习、回放和程序调试，不作为独立AI训练/验证/测试集。** 不把相邻帧随机拆成训练与测试来报告准确率；后续需不同源种子及独立真实采集会话。

每块名义采样时长约2.133ms。跨DMA块的缺口未知，因此程序切换采集块时清空瀑布图；时间轴只表示当前块内采样时间，播放速度不代表射频吞吐率。数据全到电脑不等于连续无丢样。

功率使用ADC数字码值counts²，未校准为dBm。频谱峰值是1024点FFT的频点估计，分辨率30kHz；不是经过仪器校准的目标中心频率。界面“ROI内99%能量宽度”描述选定频谱区域的能量分布，不自动等同已验证信号带宽。发射名义偏移+960kHz，实际观测约+994kHz，包含两台未校准射频参考之间的相对频偏。

本包不执行发射、采集、串口连接或AI推理，也不会修改板卡。P46已知参考EVM等质量结果见各JSON，不能当成盲AI识别率或独立BER。
