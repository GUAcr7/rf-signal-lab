# 大模型协作记录

本目录记录项目开发中的用户提示词、模型可见回答和纠错过程，供核对方案形成、代码修改及验证依据。`messages.md` 用于阅读，`messages.jsonl` 用于检索；记录附时间、源行号和来源摘要，来源说明见 `provenance.json`。

导出范围为已留存的项目本地 Codex 会话文字，不含工具调用输出、图片、其他二进制媒体、系统或开发者指令，也未汇集其他会话。环境信息和疑似凭据已隐去，其余记录保留原文。

可检索 `fixed_fir`、`P07`、`P37`、`P52`、`P74` 和 `STOP`，并与 `docs/experiments/` 及 `results/` 下同阶段的原始记录对照。历史回答中的完成状态需结合后续纠错和验收证据判断。早期 FMQL/NPU 讨论属于已放弃方案，当前实现为 Zynq/ARM/AD9361。

本目录是开发协作记录。射频识别模型运行时产生的 `ai-history.jsonl` 则属于算法运行日志，两者用途不同。
